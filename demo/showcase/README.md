# 可下载的物间演示档案

项目负责人明确授权将自己提供的实拍及演示对话作为展示资料随仓库分发。首次在全新本地库以演示模式启动时，应用导入本目录；已有账号或记录的数据库不会覆盖。进入“小林的物间”即可查看，另有小夏、妈妈和姥爷的演示角色。

本快照包含4个演示账号、60件物品（包括归档，小林当前可见44件）、13段回忆、30段对话与84条消息、10项持续任务，以及关联的来源和照片。唱片机、佳能EOS R5、LOKLiK AS2烫印机、红色咖啡机、融蜡灯、按摩椅和华为耳机均保留对应实拍。人物关系、部分拥有情况和故事是演示设定；原模型对话保留当时的实际回答，不能冒充新问题的预置答案或全体功能均已验收。

`catalog.json`是可审查的业务JSON，**不是本机数据库副本**。`media/`包含128份引用媒体，约36.4 MB：103张图片、21份工作台源码版本、3份PDF和1份用户提供的AS2视频。`assets_manifest`逐项列出文件路径、字节数、类型及SHA256，导入前会核验。耳机控制台v20和小游戏v18保存原源码字节及原检查摘要，未重新伪造实物验收；AS2已发布的校准素材保留原字节和方向设置。

下载后无需API Key就可以浏览已录入物品、回忆和历史对话，开启新云问答仍需自行配置百炼Key。历史控制台可以打开，但下载演示包**没有原电脑的蓝牙绑定或地址**，操作真实耳机前需要在自己的电脑重新连接、绑定并确认设备。

只打包已引用的展示文件。B站原链接、来源简介和实际已采样帧保留；7份第三方整片缓存不再分发，新的视频时间窗分析需以`parent_source_id`对应的原始来源重新联网调用观察工具。直接对旧抽帧来源继续请求新窗口，会诚实返回缓存不可用，不假装仍有整片；已留存的帧仍可以查看。网页来源保留已读正文和链接，不分发原网页脚本或其嵌入令牌。官方PDF及第三方产品外观的权利仍属于原权利人，本目录不另行授予这些资料的版权。

不包含密码Hash、API Key、认证Cookie、登录会话、模型运行日志、私有Agent状态或硬件地址。图片已检查无GPS；新实拍有元数据时归一方向并移除元数据，原本已公开且核验无GPS的AS2校准素材保持不变。相机铭牌序列号照片没有纳入，正面和另一张外观照保留。本机原文件和数据库未改动。

维护者可用 `.venv/Scripts/python.exe scripts/export_showcase.py` 从指定演示账号重建快照。脚本仅以只读方式读取数据库，拒绝需要改变已检查工作台源码的导出；导出修改后应运行展示包测试和新库HTTP旅程，再按正常PR合入。
