## 预先固定的条件与判断边界

- 主库只读抽取灵感目录枚举的公开原文；在隔离 SQLite 为合成账号重建 102 条当前灵感，不复制私人会话、记忆、账号、媒体资产或实物状态。
- 复用现有百炼配置，不换模型、不注入答案或评分表。保留首答、所有工具事件、供应商非流式原始请求/回复、SQL 前后状态、HTTP 可见视图、耗时和调用账本。禁止把 HTTP 200 或模型自评当作通过。
- 运行中代码条件按启动时文件 SHA256 留存。首答失败必须保留；后续修复复测另记，不能覆盖独立首次结果。
- 不触碰 8000 主服务、不重启它、不做真实设备写入。只验证软件可见的计划、记录、提醒、赠礼和权限结果。

### P1：合法的官方泛资料被错套到具体面板

补充第二题首答 78.4 秒。模型通过真实 search_public_web 与 fetch_document 找到两份爱普生官方 FAQ，建议喷嘴检查而没有直接耗墨清洗，这个大方向合理。但它给 L3256 的面板操作是按住“进/退纸”键加电源，沿用了[旧泛 FAQ](https://www.epson.com.cn/faq/fd8ff10527ec4e21bcdb66ad78d9cff8.html)的面板和松键时机，并引用[有运输锁的 L 系列 FAQ](https://www.epson.com.cn/faq/ae8af47db8d842169c6bc0c30667b373.html)。

独立验收者在首答完成后才查询并打开正确的[L3251/L3253/L3255/L3256/L3258 官方用户指南](https://download4.epson.biz/sec_pubs/l3250_series/useg/sc/manual.pdf)。其中第19页为面板与按钮、第71页为喷嘴检查：应使用停止图标按钮，电源灯闪烁后松开，和首答给出的旧机型“进/退纸”按钮不一致。这份正确手册没有预先提供给 Agent，未用事后查到的答案包装为 Agent 已会。

结论为 **型号指导未通过**：官方域名与忠实引用仍不足以证明具体机型适用。需由产品指导负责人解决型号、地区和图示面板适用性核验，不能为这个测试型号塞固定答案。
