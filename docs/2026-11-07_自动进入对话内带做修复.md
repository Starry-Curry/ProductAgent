# 自动进入对话内带做修复

## 问题与改动

普通“怎么连接、用不了”过去主要得到散文回答；全局对话未选择物品时，详细教学检查也可能漏过。“生成讲解、3D、实时跟踪”还可能误走网页工作台，生成另一个页面。只有标题的任务没有 `entry.guidance`，前端无法挂接真实的步骤、图解和相机模块。

仍使用同一个 AgentScope 主 Agent、SQL 任务库和来源工具，没有新增分类模型或第二套任务系统：

- 全局操作求助可根据当前库存中唯一的名称/型号关联物品；不唯一时保留未知，由主 Agent 语义核对。`assistance_mode=teach` 和实际目标 ID 支持不包含触发提示词的表达。
- 增加 `start_guidance` 业务工具，直接经过既有计划、权限、来源和回答校验写入当前对话的原生任务。既可先问一个具体观察问题，也可在读到适用原文后用行号发布操作。后续更新同一任务，保留既有条目、状态和实际反馈。
- 原生教学请求不能创建网页工作台；明确的软件、网页、游戏或控制面板委托仍能使用已有工作台能力。
- 等待用户才能提供的现场反馈时停止检索；需要研究时先交付可核验的当前一步，限制反复搜索。指导入口使用较快的非思考模式，AS2 专用教学包保持原路径。
- 保存步骤即推送任务事件，网页在模型研究尚未结束时就能显示带做工具；后续对话继续保持 guidance 上下文。
- 只有标题的首轮教学提纲会要求同一个 Agent 修正。恢复回答优先使用本轮实际保存的步骤，不凭空生成参数和实物结果。

`product-guidance/SKILL.md` 记录同一工作方法。文字可自然解释，计划记录状态，不用固定回复模板取代主 Agent 的正常回答。

## 验证与边界

离线针对性验证覆盖无口令进入、语义进入、已有错误工作台、更新同一任务、未读来源拒绝、来源适用性、连续进度、AS2 和工作台。89 项相关功能回归、42 项针对性回归及最终新增入口测试通过；这些组有重复覆盖，不按相加数量宣称独立案例。

真实百炼验证使用公开展示包的文字，去除并阻断照片发送，独立数据目录运行：

| 输入 | 结果 | 本次耗时 |
| --- | --- | --- |
| 家里的打印机怎么连不上了？怎么开始打印啊？ | 关联 L3256，当前对话建立原生观察步骤 | 22.27 秒 |
| 我的耳机已经拿在手里了，我想让手机里的歌从它里面放出来，陪我弄好这件事吧。 | 主 Agent 按语义进入 FreeBuds 4E 带做，核对手机系统 | 33.55 秒 |
| USB 直连，有亮灯，电脑端显示脱机。 | 同一打印机任务更新当前步骤，核对电脑系统，没有复用原来的 Wi-Fi 问题 | 23.94 秒 |

这证明自动进入与连续核对路径，不等于实物已连接或整套维修已经验收。较早失败和超时结果保留于本地隔离验证目录，不作为成功案例。打印机和耳机没有新增专用教学包或产品判断分支。

3D 与相机复用原有模块：显示入口不等于具备每个型号的精确实测模型；通用示意必须按示意理解。相机需要用户点击并授予浏览器权限，系统不会暗中启动摄像头。此轮未验证真实设备操作和真实摄像头追踪准确率。

桌面和手机尺寸的浏览器检查使用离线 Agent 测试边界，验证同一对话内的步骤、3D、相机、确认入口和无横向溢出，不把离线模型结果当作真实内容准确性证据。
