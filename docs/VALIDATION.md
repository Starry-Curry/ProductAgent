## 验证原则

后续变更应继续遵守：

1. 离线单元测试使用模型替身，不能称为真实模型成功；
2. 浏览器脚本通过不等于平台、网络和 Volume 已通过；
3. HTTP 200 不等于业务输出正确；
4. 引用合法不等于语义和实物安全已经证明；
5. 预置演示、本地规则和模型生成必须继续显式区分；
6. 未执行或失败的检查必须记录，不用“看起来可用”替代证据。
