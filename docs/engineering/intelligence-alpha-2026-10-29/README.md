# 物间智能核心 Alpha：已交付与未过关的部分

2026-10-29；分支 `codex/wujian-intelligence-alpha`，未合并 main。代码起点为已验证功能分支 `1cb9764`，不是声称 main 已具备这些能力。继续采用 LangGraph + SQLite + Next.js，没有新框架、知识图谱平台、生产数据库迁移或硬件操作。

**物品资料与自然记忆可以体验；创意质量没有过关，尚未证明比直接千问更有用。** 本轮交付业务代码、页面和测试，不以文档检查代替产品验收。

## 用户能看到的改变

- “发现新玩法”新增真实商品知识实验入口：看官方事实、型号、未知和有条件的用途推导；明确操作后才添加私密的合成测试记录，不代表本人拥有。物品详情也显示这份知识。
- “问物间”可选择从当前自然交流建议记忆。模型提取兴趣、近期目标、赠送故事的连续原话；先作候选、默认不上云，确认后才用于长期认识。候选出现时展开记忆面板，可以纠正、忘记或单独授权上云。关闭提取不增加这次模型调用。
- 事实型关系回忆（谁、何时、更正）直接取当前获准记录，避免模型添写人物留言；故事润色也拒绝来源中没有的引语。普通叙事仍不能保证完全没有语义幻觉。
- 创意加入性质引用、每件物品的作用、用户得到的成果、条件检查、失败替代与采用的偏好。物品和目标两种入口继续复用规划器。默认先给一份方案，发现页默认再做一次反例检查；确认写入、权限、工具结果往返保留。
- 修复了勾选多件物品却因短名只匹配一部分、导致其他资料被删除的问题；否定粘贴不再需要胶带，引用已知尺寸也不等于需要尺子。修复请求也重新过滤私人库存。
- 草稿不合格时不再塞入无关的观察模板；明确区分候选不合格与模型超时。旧收藏/反馈继续保留，用户报告有效仍不等于平台实物验证。

复用项目现有 Cheerio/网页/PDF 解析器，读取两张中国官网页面及松木盒组装 PDF。PDF仅提取到115个文字字符，主要是图示，未据此编造装配步骤。事实包为人工核对的小样本，未实现任意商品的自动理解。未抓取天猫页面或验证这两个 SKU 当天在天猫出售；不声称接通了天猫商品接口。

透明盒可用于“看得见内容的进度容器”、带提手木盒可用于“可搬走的活动工作站”，**这些是性质到作用的初步推导，不是已验证的新用途或用户已有物品**。每项保留条件和适用型号。没有将官方外尺寸当内部净尺寸。

## 怎样体验

本机工作区：`D:\ProductAgent-LifeContext\.runtime\alpha-app`，原项目未切分支、未动私人库。安装和构建后，在该目录运行：

```powershell
npm ci
npm run build
node scripts/alpha/preview.mjs
```

打开 `http://127.0.0.1:3201`。默认关闭真实模型、使用 `.runtime/alpha-preview` 的独立合成数据。先进入“发现新玩法”的商品实验；再进入“问物间”勾选建议记忆，聊“我喜欢安静的故事”。离线只是本地提取规则，不能当作真实模型效果。

本轮有预算的真实模型体验命令（凭证仅在网关进程中用于认证，不复制文件）：

```powershell
node scripts/alpha/preview.mjs --cloud --live-max=100-cny=20 --config=D:/ProductAgent-LifeContext/.env.local
```

费用沿用本轮累计台账；测试已用72次，最多还剩28次，或先达到20元估算上限即停止。不要删除台账重新获得额度。未来一轮应另行授权并建立新任务台账。不要同时运行两个云端实例。
