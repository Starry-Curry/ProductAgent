# 现有系统怎么测试和体验

2026-10-18：北京百炼 `qwen-plus` 已真实接通。API Key 只由本机程序用于认证，没有输出给助手、页面、日志或报告。此前“未在线验收”表示当时没有发真实请求，不表示 Key 无效。

## 打开应用

本次已启动：**http://127.0.0.1:3100**，先使用“小林”角色和“标准版”。日常启动入口是 `D:\Project\Tianmao\ProductAgent\START.cmd`；当前服务已在运行时直接打开网址即可，不必重复启动。

当前本机 `.env.local` 的非 Key 配置已完善：北京兼容地址、qwen-plus、非思考模式、开启用户主动的云端调用、关闭外部 tracing。Key 行不用于配置展示或报告。公开模板仍默认关闭付费调用。

本次启动的进程号记录在忽略文件 `.runtime/local-app-process.json`。需要停止当前后台服务时，可在项目目录运行：

```powershell
$localApp = Get-Content .\.runtime\local-app-process.json | ConvertFrom-Json
Get-NetTCPConnection -LocalPort 3100 -State Listen -ErrorAction SilentlyContinue |
  Where-Object { $_.OwningProcess -eq $localApp.pid } |
  ForEach-Object { Stop-Process -Id $_.OwningProcess }
```

随后双击 START.cmd 即可重新启动。用 START.cmd 正常启动的服务可在其窗口按 Ctrl+C 停止。没有修改配置时不需要重启。

## 先测试真实 AI 回答

1. 首页保持“还没保存的物品 / 不确定”。
2. 输入：**帮我把“先把桌上的纸张归到一处”变成一句不催促人的行动建议。**
3. 点击“帮我解决”。应出现“AI 一般帮助”的自然回答。它是实际模型请求，不是固定商品资料。
4. 再补充“我现在比较累，帮我把目标再缩小一点”，观察连续回答。输出措辞每次可能不同。

一般请求的本轮实测约 1—2 秒，工具往返约 5 秒；这是小样本观测，不是延迟保证。云端请求可能计费，具体以百炼账户账单为准。

## 使用帮助的闭环

1. 首页问“鼠标双击速度怎么调”，补充“Windows 11”。
2. 查看 3 个设置步骤和 Microsoft 来源。这里展示的是有来源的精选指导，不需要每次调用模型。
3. 点第一步“这步试过了”，再说“还是不行”，检查它是否保留系统条件并跳过已试步骤。
4. “还没解决”可以记录卡点，再点“继续排查”；解决后由你点击“解决了”。
5. 未建档的问题可在下方选择已有物品，之前的澄清与尝试会继续保留。

型号专属帮助仍需要准确资料。目前有 M185 两个硬件版本、JBL Go 4、指定货号 IKEA RÅSKOG 的资料。没有核对型号时不要替实际物品勾选“已核对实物”；没有覆盖的型号会要求补资料，不保证能回答任意维修问题。

## Memory、兴趣和陪伴

1. 首页展开“关于我与记住的事”。保存兴趣“我喜欢手工和拼豆”，默认仅本地；也可在对话里说“记住：我喜欢手工和拼豆”。
2. 进入“发现”，展开“结合我记下的兴趣，找点灵感”。问“用家里的东西找点灵感”，再说“今天不想手工，换个方向”，观察当前意愿是否优先。
3. 回首页保存一条真实故事，开启“可选陪伴的交流方式”，设置称呼与语气并保存。可以问“聊聊以前的故事”。
4. 想测试真实工具循环，可在陪伴对话里问：**先看看我当前可访问的物品有哪些，再结合我的偏好，选一件推荐一个温和的小目标。** 系统会按需要查询可访问的物品清单。
5. 只有逐条勾选云端授权的个人记忆才能提供给模型；默认的本地故事也可由本机精选逻辑引用，不代表已发给云端。
6. 纠正或忘记一条记忆后，旧对话上下文会清除；再次提问不应恢复旧原文。原“故事与记录”稿件和已分享的摘要是独立记录，须在对应入口管理。

## 其他现有模块

| 模块 | 建议操作 | 观察点 |
| --- | --- | --- |
| 我的物品 | 查看或新增一件演示物品，补充资料 | 物品归属、共享和型号关联保持分开 |
| 活动准备 | 点击“周末四个人去野餐”或“准备出门旅行” | 区分有记录、待核实和需要准备的项目；可以自行修正 |
| 家庭事项 | 从一件家庭共享物品点“请家人帮我”，预览并确认摘要，再切换“爸爸” | 家人接收事项与最小摘要，不自动获得私人记忆和完整会话 |
| 发现 | “核对可用组合”，或打开现有创意候选 | 显示条件与约束，不把候选说成实物验证 |
| 礼物与记忆 | 使用演示物品，选择要附带的故事再体验赠送/收礼 | 仅选中内容流转，原作者保持；会改变演示物品归属 |
| 长辈版 | 右上角“版本”切换 | 简化导航、大字号与主要提问入口；高级记忆设置默认折叠 |

固定的“小林 / 爸爸 / 小夏”是本机演示角色，不是真实跨设备账号。建议先用演示物品测试赠礼和归属变化。
