❌ 不引入新物品（如手机、纸条、骰子、APP、蓝牙模块等）

### 🌍 方向一：**「旋钮即签筒」——用按压节奏生成伪随机旅行地**

**做什么？**
把每次“按下旋钮”的动作，映射为一次「心理抽签」：你按下它，就同步在脑中/口中念出一个预设旅行地列表中的某一项；下一次按，跳到下一个——但**不按顺序，而靠「按压停顿节奏」来决定跳几步**。

**借用什么特性？**
- 旋钮按下是明确、离散、有反馈（灯会闪/变亮/熄灭）的物理事件
- 用户自然会产生「等待反馈→松手→再按」的节奏感
- 人类对自身节奏的微小波动高度敏感（且不可复现），这本身就是一种**生物随机源**

**怎么玩？**
1. 提前写好7–12个你想去的旅行地（如：京都、雷克雅未克、清迈、里斯本、敦煌、塔斯马尼亚、瓦努阿图…），列成环形列表（首尾相连）
2. 每次按下旋钮 → 心中默数「1」，同时看灯是否亮起（或听咔嗒声）
3. **松手后，凭直觉等「1～3秒」再按第二次**：
　　- 等1秒 → 跳1位
　　- 等2秒 → 跳3位
　　- 等3秒 → 跳5位（斐波那契式跳跃，增加非线性感）
4. 第三次按下时，停在当前位置的地名就是本次「抽中的旅行目的地」

**为什么有效？**
- 完全无需外部工具，只调动你的注意力与身体节律
- 节奏判断无法精确复制 → 每次结果主观随机，且有参与感
- 灯的视觉反馈（明/灭/渐变）成为天然「确认信号」，替代传统签筒摇晃后的静止时刻

**延伸彩蛋**：
若台灯支持多段亮度（如米家1S可调0–100%），可约定：
- 按下时亮度落在 0–33% → 抽「冷门小众地」子列表
- 34–66% → 「文化沉浸型」
- 67–100% → 「自然野趣型」
→ 用已有模拟信号做第一层分类，再在子列表内节奏跳选

### 🧭 方向二：**「光暗即卦象」——用开/关状态序列编码旅行意向**

**做什么？**
把「按下旋钮导致的灯状态变化」当作二进制输入：
- 灯**从灭→亮** = `1`
- 灯**从亮→灭** = `0`
连续按3次，得到一个3位二进制数（如 `101` = 5），对应预设的8个旅行关键词（000 到 111）

**借用什么特性？**
- 米家1S旋钮默认功能：单按切换开关（灭↔亮），这是稳定、确定、无需学习的固有逻辑
- 开关状态切换是清晰可辨的物理结果，无需观察内部电路

**怎么玩？**
1. 准备8个旅行关键词（非地点，而是「旅行气质」）：
　　`000`=漫游者　`001`=朝圣者　`010`=采风人　`011`=隐士　`100`=闯入者　`101`=摆渡人　`110`=拾荒者　`111`=归途人
2. 从灯**灭态开始**（手动关掉，确保初始态一致）
3. 连续按3次旋钮，记录每次按下后灯的**变化方向**（不是当前状态！是「变亮？」或「变灭？」）
　　例：灭→亮（1）、亮→灭（0）、灭→亮（1）→ 得 `101` → 抽中「摆渡人」
4. 再查「摆渡人」对应的实际目的地建议（可贴在台灯底座旁，或存在手机备忘录里）

**为什么有趣？**
- 把最基础的开关行为升维成「占卜界面」，零成本获得叙事张力
- 3次操作极短（<5秒），适合碎片化灵感激发
- 可扩展：按5次得32种组合 → 绑定更细颗粒度的旅行人格/季节/预算倾向

### 🌐 方向三：**「地理谐振法」——用旋钮按压次数匹配真实世界地理参数**

**做什么？**
放弃“随机”，转向「伪决定论式浪漫」：让按压次数与某个客观地理数据产生巧合式关联，制造“世界在回应你”的错觉。

**借用什么特性？**
- 人按下旋钮的次数是自由、离散、可计数的整数
- 地理系统中存在大量公开、稳定、带诗意的数字：
　　• 全球现存国家数量 ≈ 195
　　• 中国陆地边境线长度 ≈ 22800 km
　　• 北京到巴黎飞行距离 ≈ 8200 km
　　• 世界最深海沟（马里亚纳）深度 ≈ 11000 米
　　• 国际日期变更线曲折度 ≈ 无数次折角（但可取其著名经度：180°）

**怎么玩？**
- 你专注想着一个旅行大区（如“南美”、“东南亚”、“北欧”）
- 然后**不停按旋钮，直到自己觉得“够了”**（不数，凭气息/手感停）
- 数总次数，查表映射：
　　| 次数区间 | 解读方式 | 示例 |
　　|----------|-----------|------|
　　| 1–3      | 对应「该地区最著名的1个坐标点」纬度/经度个位数 | 南美→按2下→查「里约热内卢」纬度22.9°→取个位“9”→第9个备选城市（如萨尔瓦多） |
　　| 4–7      | 对应「该地区UNESCO世界遗产数量」模10 | 东南亚133处→133%10=3→第3个遗产地（吴哥窟） |
　　| 8+       | 对应「最近一次该地区发生日食的年份」末位 | 下次印尼日食2027→7→锁定7月出发 |

**为什么成立？**
- 所有数据真实存在、可验证、非虚构
- 用户不需记忆数字，只需接受“我按的次数，碰巧连上了世界的某个刻度”
- 弱规则 + 强联想 = 低门槛高满足感，类似翻黄历择吉

### ✅ 三个方向共通优势：
- **零新增物料**：仅用台灯本体 + 你的注意力 + 一张手写纸（可选）
- **尊重原设计**：不扭曲旋钮功能，反而放大其「确定性反馈」的价值
- **可随时中止**：没抽中喜欢的？再按一次——游戏规则由你即时重写
- **留白空间大**：每个方向都可自行填充旅行清单、定义关键词、调整映射逻辑
