# 本轮收敛决定

1. **默认单次自由探索，案例启发可选。** A/B/C 在同模型下没有显示可稳定推广的质量优胜者；混合组传输成功率较高不等于创意更好。默认减少强制步骤与序列化，直接响应用户要求，不宣称胜过直接模型。
2. **先想法，选中后再核对。** 第一阶段不设固定创意数/字数，不把 `candidates<=3` 的旧包契约用于开放结果。去掉最终列表隐含的 6 条裁剪；交接可携带更多方向，历史输入仍有防滥用的有界容量。旧引擎保留为显式 `legacy` 回归/回滚路径，不是新入口默认。
3. **保留有条件的概念，不伪造实施结论。** 选中阶段使用动作及必要属性表示，并以程序补齐容纳、占地、支撑、夹持等依赖。来源编号不证明弹性、磁性、稳定性；外尺寸不证明内部容纳。存在冲突或关键属性未知时，概念没有操作步骤。模型自然语言的完整因果与心理效果仍未被验证。
4. **小型出处索引，不建设未经授权的数据管道。** 8 条原创摘要以可替换检索接口供调用。未知许可不推为开放授权；不收录教程全文、图片或代码。案例里需要的工具不会自动成为用户库存。没有语义检索、实时社区更新或小红书笔记 API 成功的宣称。
5. **不自动切换模型、不开启生产思考模式。** 20 条小样本验证了 qwen-plus / qwen3.7-plus 的接口及思考/轻JSON配置；更强型号和思考仍有明显物理错误。轻JSON较快但同样能编造。既有 AI_CREATIVE_MODEL 可覆盖，未修改根配置、账户或全局环境。
6. **隐私与任务连续性随新体验补齐。** 反馈备注仍需明确选择及同意。新创意带生成时的记忆版本，记忆/授权变化后不能重新作为云端上下文；在途资料/权限变化拒绝持久化。概念回到统一对话仍标注未验证。旧输出中的事实不能自动写入物品属性或记忆。

## 明确停止与后续

本轮不再追加提示词和模型试验，不开始 V3/V4。后续优先整体 Agent 与前端体验、真实用户任务需求，以及自有软件目标的只读 REA PoC。进入设备前仍需：执行器隔离、按目标/版本授权、能力证据、幂等、状态回读、撤销与失败审计。当前动作检查不能替代这些设施。

尚需产品判断：是否把当前探索入口作为明确的概念原型展示；后续真人评价应优先实用重定义还是强新颖性。无需因此阻断本轮独立分支交付。没有大规模架构或数据库重建的实证依据。
