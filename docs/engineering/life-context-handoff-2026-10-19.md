## 启动与恢复

在 `D:\ProductAgent-LifeContext` 使用 Node 24：`npm ci --cache .npm`、`npm run build`、`npm run start:life`。也可双击 `START_LIFE.cmd`。默认 `http://127.0.0.1:3200`；`npm run dev:life` 为开发模式。修改代码后必须重新构建，启动脚本只在缺少 BUILD_ID 时自动构建。端口已占用时先确认现有服务，不能覆盖其他进程。

新版数据库默认 `data-life-v1/demo.sqlite`，测试是 `.runtime/verification-*` 的全新目录。`lifeDataDirectory` 解析真实路径，拒绝旧 `data/`、其他工作区和从 `ProductAgent-Dev` 启动；启动器按自身位置固定工作区。不要复制旧库、照片或 `.env.local`。旧版仍可从原目录按原说明运行；当前分支 `/legacy` 保留原页面和业务链路。

启动器强制关闭 AI_ALLOW_PAID_CALLS/WUJIAN_ALLOW_PAID_CALLS 及外部 tracing。历史环境文件里的付费开关不等于本轮费用授权。已复用 Qwen Provider；只有另获费用授权并正确配置后才能联调真实问答/模型创意，不能把离线替身视为在线成功。

## 用户路径

1. 首页载入合成案例，或“录入物品”。名称、品牌、型号、类别、生命周期、属性与可用状态由本人确认。图库上传并非视觉识别；条码/二维码实际本地解码，但编码不等于型号或说明书。公开 HTTPS 链接仅由用户主动读取，受限网页可提供获准片段；PDF/TXT/MD 在本机提取文字并确认后绑定物品。
2. 展柜打开物品，“帮助”复用 AssistantConversation → LangGraph → Product Pack/用户资料/Provider → 验证及反馈。无型号资料时不编参数；用户上传资料明确是未独立核验的摘录。AA 电池和两个预审过程可以离线验收。
3. “发现新玩法”从当前可访问、可用物品匹配单件/组合、时间和当前要求，支持收藏、尝试及反馈。12 类本地配方动态匹配实例，不是任意语义创造。模型生成路径已接 Provider，返回时复查物品权限/状态；未做真实模型质量验收。可以主动提交经验、链接、所需物品、步骤和限制，保存为用户候选，不抓取社区全站。
4. “生活故事”或物品“故事”中照片＋原话保存一份片段，多物品仅存关联。可编辑、解除关联和删除。主动请求回忆时可本地引用本人片段，普通设备问题不读这些片段。默认不把它提炼成心理画像。
5. 家庭沿用领域授权和演示成员；物品共享与私人故事分离。事项真实写入本机并由负责人更新，不能冒称通知真人。赠礼明确预览后只复制选中的文字快照，保留作者；照片、聊天与画像不随之流转。

## 数据与模块

- 保留 SQLite v6 和 workspace JSON 的既有迁移。`life_schema` 独立增量版本 1；升级前 `.before-life-v1.sqlite` 备份。没有升级或访问旧日常库。
- life_fragments/life_fragment_items：唯一原文及多物品关联；owner、revision、事务和过时修改拒绝。作者可在转赠后保留自己的片段，不能新关联无权物品。
- life_media：经过格式解码、像素/大小检查、旋转与压缩的 JPEG BLOB；移除 EXIF，原图不保留。读取检查 owner/关联物品权限，使用 private/no-store。片段删除时删除无其他引用的照片。取消上传的未引用草稿尚无定期清理；数据库备份不承诺即时擦除。
- life_sources：本人提供/主动读取的资料，独立于官方 Product Pack；共享物品不自动分享私人文件。HTTPS 仅单页、限时限长、拒绝重定向/私网，DNS 固定到已校验地址。PDF 前 20 页内文字提取，扫描 PDF 不具 OCR；原 PDF 不持久保存。pdf-parse/pdfjs/native canvas 保留为服务端外部依赖，避免生产 worker 丢失。
- life_ideas/life_idea_feedback：按 owner 保存来源、条件、资源与实际反馈。用户报告有效不升级为实物验证。零数量、过期、借出/损坏/未知状态不作为可用资源。
- 既有个人记忆、来源回执、slot 锁和 epoch 继续使用。新版默认 memoryPolicy=off，只保留必要会话；可选择 candidates，待确认后才用于长期个性化。历史回扫及反馈同样遵守政策。显式“记住”仍是保存指令；旧入口 legacy 行为保留供回归。
- 普通对话可在获准会话内传递最近用户/助手消息；历史私人记忆仍须逐条 allowCloud。照片、生活片段不自动上云。文字 Persona 仍需主动开启；新版无默认二维角色或空间录入要求。
