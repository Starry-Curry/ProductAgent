# 逐层对抗审查：覆盖边界与反例

这份清单响应“每个步骤、层级、功能都做对抗审查”，记录有限范围内实际尝试的反例，**不声称穷尽所有攻击或所有产品功能已经可靠**。判定依据是原始输出、领域状态和权限，不是模型自评分。产品范围沿用 [F1–F12](../../product/PRODUCT_FINAL_V1.md)。

## F1–F12逐功能审查

| 能力 | 正常路径及对抗路径 | 当前结论 |
| --- | --- | --- |
| F1 物品进入 | 手工真实型号、合成持有确认、可访问官方链接、照片逐图同意；无文字图形、未同意/未登录/外账号 | 手工与两张合成图真实流程；照片不认证实物。通用订单/条码商品库未接通 |
| F2 单物品服务 | Brother、KORG、Victorinox等真实问答/续问；窄标签限制、错误版本、无资料、未知地区 | 有明确成功与失败；六陌生型号远未全通过，不能称陌生商品通用可靠 |
| F3 目标与组合 | 原Task选择相机/云台，改目标不用云台；重量来源计算、未知镜头/支撑、无额外购买 | 重量拦截有效；复测仍编入书本/支撑与能力过度承诺，任务质量未通过 |
| F4 创造力 | 原物品开放发散→反馈→选择深化→候选Task；不强迫所有物品参与，未知尺寸不能认证 | 真实开放输出存在，但机制牵强、平常用途与隐含资源问题仍在；未证明创新度提升 |
| F5 设备探索 | 实际REA分析自有软件目标→显式授权→写入/回读→同Task；幂等、撤权、目标哈希与重启状态 | 软件范围实际运行；没有任何真实设备逆向/控制。不是通用设备适配器平台 |
| F6 个性化/分身 | 画作关系、可选人格、实际软件回读；分身名≠用户，事实不由人格创作 | 新会话关系更正/遗忘与软件状态实际验证；布置建议仍有物理错误，无生成形象升级承诺 |
| F7 故事记忆 | 用户故事→明确候选/确认/云端→新会话→纠正/忘记；候选、旧聊天、私事、来源撤销 | 协议与来源修复有真实证据；自然交流候选模式仍实验，不能因读到记忆宣称理解用户成熟 |
| F8 生命周期 | 真实页面数量0/过期→Reality→创意候选排除→明确更正恢复；JP版本编辑与匿名读取 | lifecycle-r1暴露API不接受JP，r2零模型实流修复通过；未对真实食品安全或保修作认证 |
| F9 家庭协作 | 两个独立账号按件授权、共享摘要、同Task接手报告、撤权；省略homeId/私事外传攻击 | 实际Qwen+UI协议记录；未实际完成打印/照护。私人信息不靠模型自觉隐藏 |
| F10 赠礼流转 | 选择既有故事快照、独立认领、收礼人另授记忆/云端；旧token、双重认领、私事/人格自动继承 | 真实UI/Qwen及幂等反例；合成赠礼不是实物交接，当前故事快照是文字，不宣称完整图文传承 |
| F11 Agent/任务 | 同一Task跨物品/故事/软件、目标调整/刷新/进度；旧会话覆盖、重复失败工具与条件遗漏 | 状态断点已修；重复模型推理与强制计划仍有限制，智能任务完成率未达发布门槛 |
| F12 可信/权限 | 原文哈希、型号/地区范围、用户报告分离、多账号、授权撤回、费用锚点 | 有有限范围的真实与离线反例；尚不能证明模型自然语言事实及全部隐含资源可靠 |

## 判断纪律

### 切片8新增反例

- 离线Mock只证明协议、状态、事务和权限，不能计作真实模型或实物通过。
- 每个已复现问题保存 before/after；脚本错误、资料发现失败、模型误读、最终呈现错误分别记录。
- 所有首答保留；复测不覆盖历史18题0/18，不把本轮开发样本算正式留出验收。
- 发现新反例优先修复对应机制，不加品牌答案、SKU正则或第二模型审稿。仍不可靠的候选默认关闭。
- **Core/Full及全产品仍NOT_ACCEPTED**。逐项做审查不等于逐项已经完全实现或证明安全。


### 切片9新增：不只检查正常路径

- 来源：非法辅助链接、同页fragment、不同查询版本、旧缓存别名、新写失败回滚、原文字节不变但地区更正、失去厂家父页链接后仍贴继承标签、公共分类目录错绑另一SKU。证据见`source-lifecycle-*`、`source-annotation-*`、`category-path-scope-*`、`linked-scope-*`。
- 模型工具：用恶意厂家正文诱导跨账号读取、另一实例sourceId、未经确认保存故事；`source-injection-boundary-r1`三项离线反例，均不放大读取/写入权限。不声称真实模型免疫注入。
- 身份/流：退出发生在异步等待或真实Qwen在途，旧会话不收私人迟到响应/最终答案；安全固定登录错误可显示，实际下一次私有读取401。不能撤回已发送的供应商输入，也不自动撤销早前已确认事务。
- 台账：私人预览的异常也不记录上游回显，仍保留失败请求/未知用量预留；正常私密预览的实际2请求账目不含输入输出/输入hash。合成评测记录与历史锚点保持原样。
- 图书/编码：校验位错误、社区候选升官方/升持有、ISBN对应书名误记、作者充当厂家。新映射作者独立展示，原文来源与许可保留；QR为生成测试图，不称实物扫描。
- 呈现：原文卡片曾在390px手机被挤窄，实截图后改限高/宽度检查；原文ID相同不同实例、九章之后仍active的已读原文都有绑定反例。展示原文不是语义认证。

此前“未验证条码库”的范围现更新为：Open Library和Open Food Facts两个公开众包元数据入口已有实际访问和浏览器验证；其他条码数据库、实物扫码质量及官方资料认证仍未证明。F1–F12其余未达标项不因这些修复消失。
