# 物间 V2：商品成为我的物品

**业务链路已接入 App；个性化回答质量未完全通过产品验收。** 这是功能分支交付，不是主线发布。

## 现在能体验什么

从“录入物品”输入 SAMLA、KNAGGLIG、GO 4，或粘贴下方支持的官方商品链接。先看型号事实、限制、未知及来源，再明确确认型号和持有。名称、位置、使用状态、照片、备注属于“我的这一件”，不会写进公共商品资料。体验时勾选“测试物品”，不要冒充真实持有。

物品的“帮助”现在是一张连续的生活页面：它是什么、我的实际状态、我与它的故事、可选分身、结合关系的交流。画作和其他无型号物品可展开“不是这些商品？”继续原有手动/照片录入。原有新玩法、故事编辑、资料与管理保留。

写下故事时，回忆授权和云端授权分别选择。再点“确认保留为这件物品的关系记忆”，才会进入普通帮助。在“记忆与陪伴”可纠正、调整授权或忘记。确认后的原故事保留私密展示，引用统一交给记忆管理；更改/删除原故事会撤回其派生记忆，防止旧赠送者从另一来源复活。

数字分身可自定义名字、六种形象（含自己的物品照片）、三种语气，独立开启/关闭。只是同一 Agent 的说话身份；没有每件物品常驻一个模型。物品主人才能设置；获准记忆、云端许可和当前物品范围仍分别检查。共享或赠送不会自动复制私人故事、聊天与人格设置。当前家庭身份仍是本机演示，不是真实家庭登录。

## 验收结果应怎样理解

- A：真实 SAMLA 型号 → 浏览器确认合成持有 → 私人备注 → 问答，业务与权限流程通过。材质、尺寸、限制和状态未知均能展示。**两次个性化帮助仍被校验拒绝并回退资料摘录，实际帮助效果未达标。**
- B：合成赠画 → 故事和照片 → 明确确认记忆 → 名为“山山”的分身 → 新会话 → 结合40×30厘米画作、80厘米书桌与赠送事实生成建议 → 纠正为阿禾 → 遗忘，技术链路通过。跨会话赠送者正确，纠正和遗忘有效。**模型仍有错把分身名当用户名、未经验证的免钉摆放尺寸与支撑建议；混合提问也会漏答实际目标。**
- 315项离线测试（基准307，新增8）、类型检查、生产构建、benchmark、既有六条浏览器回归、公开演示八组离线检查及生活/文件两条旅程通过。它们不能证明实体方案安全或人格体验成熟。
- 百炼14次请求全部返回；65004输入/4571输出tokens，估算0.0611452元。包括工具往返、被拒草稿、失败浏览器运行中的请求。**接口返回成功不等于应用采纳，更不等于回答质量通过。**

## 打开与复现

本机工作区：`D:/ProductAgent-LifeContext/.runtime/personal-objects-app`。独立分支：`codex/wujian-personal-objects-v1`，业务基准 `d02b35e5df2de038299def6aacb56e0cc2a7b43f`；核对远端 main 为 `ea32c3f4c9e18992ca267b6dd74e26e418c9e95a`。原项目及 `deliverables/` 未改动，没有迁移私人数据库。

```powershell
# 当前用户授权范围内的云端体验：安全读取既有本地认证配置，不复制密钥

```
