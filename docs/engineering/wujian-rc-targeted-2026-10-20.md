# RC 定向修复与独立验收补充

基于95354a3增量开发。原23项矩阵文件未修改，blob核对记录见[新增独立矩阵](wujian-rc-targeted-acceptance-2026-10-20.json)；不提升原等级。实测及失败见[脱敏记录](wujian-rc-targeted-validation-2026-10-20.json)。

## 可以操作的新增体验

- 故事书默认阅读，照片和文字分版；原文首句作展示标题，不要求填写日记标题。照片组、全文、放大、键盘退出/焦点恢复、背景滚动锁定；写作与筛选/整理按需展开。
- 章节引用唯一事件，可命名、更名、增减成员或解除；合并/拆分目前通过编辑成员、新建章节、解除旧章节分步完成，没有自动语义归类。
- “物间目前了解我的哪些事”本机整理明确偏好/目标原话，展示证据，允许纠正、确认适用任务和上云权限、拒绝、遗忘。单次模糊经历不生成确定人格。源事件改动或撤销后，派生Context失效；拒绝签名不反复出现。
- 照片去重复用媒体，完全相同事件提交复用原文。不同日期仍是不同事件；不具备语义事件合并判断。照片候选需逐件确认，未知允许空关联，相似/同型号实例不会自动合并。
- 商品指导按充电/装配/养护/烹饪显示阶段。逐步检查数字、单位、已知关键功能与否定限制，局部可用步骤保留；非关键phase缺失不再导致全答失败。完整语义蕴含验证仍未实现。
- 续接恢复原任务检索目标，并从会话原步骤识别已经完成的清洗，避免仅凭截短ID比较。在线续接网络失败，旧响应离线Graph回放不重复清洗；不能宣称A5在线通过。
- 离线整理、衣物搭配、备菜、出游和摄影增加基于资源能力的有限规划；不是开放模型质量的替代证明。旧照片整理可按目标读取美国国会图书馆真实页面，短摘录/来源/限制进入现有Creative Evidence及推荐。Wikibooks本轮仍网络失败。

## 实际机制与边界

Media继续使用life_media/Sharp；Event仍为life_fragments + details + 多物品关联；schema6备份后仅新增life_chapters（成员ID）与life_understanding（候选、证据指纹、状态、范围、Memory ID）。确认后写既有personal_memories，Context Builder及创意规划按范围、Persona与权限选择少量相关记忆，未建设第二套记忆系统。用户可在原Memory中心继续管理。

图像匹配为既有Qwen Vision候选 → 可见型号/品牌约束 → 本人非演示物品名称匹配 → 用户确认。没有CLIP/SigLIP、图像向量或可靠外观实例识别；合成图片+离线视觉替身仅验证协议和权限，真实识别效果未验收。未配置AI_VISION_MODEL，获准2次视觉请求尚未消耗。

30条合成故事测试覆盖相关主题/章节召回、无关排除、重复、确认/纠正/拒绝/遗忘、临时聊天、赠后私人保留。召回仍有词项与范围规则限制。AI自动发现事件关系、暂定长期倾向、语义章节候选属于L3；不以关键词聚类冒充事件理解。

Neo4j/向量数据库是旧设想，当前规模下SQLite的事务、外键与现有来源关系更便于隔离、备份和回归。只有真实多跳/语义召回基准证明不足后再评估新服务。沿用用户指定启发：任务/步骤Evaluation与Reference、反馈留存；低摩擦入口；少量可修改条件；按需授权Context；以最终任务质量及总请求成本衡量，不把HTTP200或模型自评当独立事实。
