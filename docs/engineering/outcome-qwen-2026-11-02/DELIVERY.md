# 物间：本轮恢复点与真实结果

**本轮未通过产品验收。状态BLOCKED_AUTHORIZATION：250次授权请求已用完，新真实验证需要另行授权。不是“完成交付，仅待优化”。** 研究、实现、反例、修复与现有资源内复验均已保存；G1/G2/G3等仍有实质差距，见[逐门槛复核](QUALITY_REVIEW.md)。

## 用户实际多了什么

- 任务不再把其他获准物品挡在目录之外；开放探索先读相关资源，物品细节不等于故事或私密备注授权。
- 能在统一对话中认识部分陌生型号，实际使用百炼原生搜索、网页抽取和按需PDF图文读取；来源和失败留存。六款里并非四款都正确，不能宣称通用商品理解完成。
- 自然目标能准备候选计划，用户确认后连入同一Task，再记录明确标注的合成尝试报告；获准后下一Task能读到报告。模型仍可能把报告说得过强，未证明长期建议稳定可靠。
- 不上传云端的物品关系可在回答末尾仅本机显示，混合问题的其他部分继续由模型处理；本机段落不进入后续云端历史。纠正、撤权、遗忘和独立账号隐私已回归。
- 方案的资源条件变化会指出受影响步骤。真实浏览器中改尺寸标出4步中的2步，改私人备注无需重做物理方案；均未重新调用模型。未变化不等于实物验证。
- 模型中途草稿不直接显示；界面流式显示处理进度。危险电池报告阻止把设备当配重/敲击件继续用，最终安全限制是确定性测试，未用替身冒充真实模型通过。

## 为什么还不能代替直接千问

物间增加的是授权物品Context、关系/经验、确认后的业务事务和跨任务持续性；**本轮没有证明创意质量超过直接同版千问**。在相同任务中三条路径都出现额外材料或无依据物理作用。新流程更快不等于更聪明。自由生成、过早严审、全结构化动作也都各有失败，不把复杂技术包装为胜利。

具体失败与至少五类原始创意可直接阅读[匿名样本](evidence/BLIND_SAMPLES.json)，版本对应在BLIND_KEY；[最后候选原文](evidence/candidate-resource-r3.json)、[直接千问](evidence/direct-valid.json)、[基线执行器](evidence/baseline-valid.json)及[陌生反例](evidence/action-contract-counterexamples.json)均保留。

## 打开和恢复

本地源码在`D:\ProductAgent-LifeContext\.runtime\outcome-qwen-v3`。Node24下安装当前锁文件依赖；隔离运行说明见[ENVIRONMENT](ENVIRONMENT.md)。本轮费用耗尽后只提供**不调用模型的浏览/恢复模式**，不能用离线回复冒充千问成功。

```powershell
cd D:\ProductAgent-LifeContext\.runtime\outcome-qwen-v3
$env:WUJIAN_BUILD_DIR='.next-outcome-final-snapshot'
npm run build
node scripts/outcome/preview.mjs --offline --port=3239
```

打开 http://127.0.0.1:3239 。现有合成账户/物品保存在本地隔离目录，未公开登录凭证或数据库；新用户可注册并显式加载虚拟家庭。离线模式可浏览、录入、查看资料及现有记录；**新真实模型回答已停用**。跨机器只克隆源码不包含这些本地测试账户，按脚本重新创建合成数据，不复制私人数据库。
