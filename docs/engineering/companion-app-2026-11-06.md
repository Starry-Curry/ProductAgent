# 物间 · 物伴版 App 交付记录（2026-11-06）

## 交付与运行

- 默认页面：`http://127.0.0.1:3210/`。原应用 `/classic`，旧界面 `/legacy`。
- Mac 双击根目录 `START_WUJIAN.command`；Windows 使用 Node.js 24、本机安装依赖后运行 `START_WUJIAN.cmd`。Windows 启动器未在真实 Windows 上实测，不能直接搬运 macOS 的 node_modules。
- 命令：`node scripts/companion-start.mjs start --cloud`；不带 `--cloud` 使用本地资料模式。首次缺少构建会自动构建。
- 数据：独立 `data-companion-v1`，原数据目录保持原样。启动器仅监听 127.0.0.1，不是公开部署。
- 本地密钥由 `.env.local` 读取，不纳入交付文档、Git 或截图。双击启动启用真实 AI，主动问答与图片识别按模型服务商计费。

## 功能与价值

1. **物伴为首页**：文字、语音与拍照入口，连续对话、已保存物品选择、引用资料与通用建议区分、可执行步骤、反馈、复制、朗读、失败重试、历史会话。大字模式聚焦问答和本人的重要待办；明确完成一步后可以继续，未找到操作时可以求助。最新问题优先于旧的「只教第一步」要求。
2. **轻量物品档案**：拍照识别后确认录入，也可只拍照提问。家庭用品和私人物品分区；搜索、位置筛选、详情、编辑、换图、状态、说明书/售后资料与物品记忆。上传照片优先，25 件合成样例照片供展示。
3. **家中需要处理**：补充、维修、清洗、暂停使用、指定负责人、知晓提醒、完成与处理记录。提醒知晓不会将故障品改为已修好。删除有确认；活动借用阻止删除物品。
4. **活动准备**：野餐、出游、摄影等有限库存规则模板，显示已有与缺少、逐项完成、分配、增删、导出与接着问 AI。规则生成明确标注，不声称覆盖任意活动的通用规划。
5. **朋友与情感**：本人想买清单可选择分享；朋友主页查看公开想买物品，主动「买来送她」，保存赠言后打开购买链接。照片、商品链接、赠言草稿持久化。可选分享物品故事、撤回分享、公开可借物品；借用需所有者确认、归还需所有者确认。
6. **物伴设定**：名称、外观偏好、表达方式保存；普通/关怀版和本机成员切换；本机数据导出。

## 实现

沿用 Node.js 24、Next.js 15、React 19、LangGraph 与现有 SQLite。`companion_records` 保存扩展实体及 revision；所有写入通过服务端域授权、事务和版本检查。前端以现有真实 assistant、workspace、media、sources 等 API 为基础，新增 `/api/companion` 承载清单、赠言、分享和借用。普通浏览器 GET 不自动添加社交样例；需用户显式加载。

文本模型沿用 qwen-plus，图片识别默认 qwen3-vl-plus。原样重复已明确完成动作的回答会进入有界纠正重试；若依旧无效则返回不足信息，不把被拒绝的回答直接返回。客户端能力标记使新界面朗读/语音能力与旧页面区别处理。

## 验收

- 离线单元测试：205/205 通过（含授权、隐私、版本冲突、借还、清单迁移和连续问答的重复纠正）。
- 生产 API：12 项检查通过，含真实文本回答、未知物品不编造专属按钮、真实图片识别、图片上传替换、任务知晓不代表修复、借还和分享撤回等；见相邻 JSON。
- 浏览器：桌面与 390px 手机布局，物品创建及记忆保存、活动勾选与负责人、朋友赠言、大字关怀版、真实物品帮助；截图保存在本机 artifacts/companion-app。
- TypeScript 与生产构建通过；现有 benchmark 无新增回归。已有抽取式校验不能证明任意改写的语义正确。
- 真实浏览器连续问答复测通过：Windows 11 首轮指导选中文件，短句「我已经选中了，接下来呢？」后正确推进到复制，没有重放选中动作。
- 麦克风、系统朗读依赖浏览器与设备；未实际打开设备权限进行录音。支付、真实客服会话与跨设备推送不属于已接入能力。

## 当前边界

这是可操作并持久化的本机演示 App。三位成员是演示身份，不是真实认证或多用户隔离服务；不可直接公开暴露服务器。好友互动在同一本机数据内完成，没有发送外部消息。购买按钮打开有效商品链接或商城搜索，付款发生在商城；售后使用保存/核实的外部入口与可复制问题摘要，没有冒充自动接通客服。账号同步、云备份与系统级悬浮窗尚未实现。活动准备为限定规则，AI 回答仍受型号、资料与服务可用性影响。
