# 本轮取舍（随实际结果更新）

## 模型与工具循环

保留 Node24、SQLite、OpenAI Node SDK 7.47.0（Apache-2.0），保留现有 LangGraph 1.5.1（MIT）的既有业务/持久任务实现。没有迁移框架。普通问答仍用自然文本，复杂任务才可开启同版 `qwen3.8-max-0902` 的思考模式；推理内容只在单次工具循环中回传，不展示或保存到用户聊天/公开评测输入。

[百炼思考文档](https://help.aliyun.com/zh/model-studio/deep-thinking)、[兼容接口参数](https://help.aliyun.com/en/model-studio/qwen-api-via-openai-chat-completions)说明同一模型可开关思考，工具循环应保留 reasoning_content。两次同原资料直调（非思考/2048思考预算）都保留了越界内容，不能据此认为只开思考即解决问题。后续 App 试用768思考预算以控制延迟，属于不同配置，不冒称完全相同配置的盲评。

对比 [AI SDK有界工具循环](https://ai-sdk.dev/docs/ai-sdk-core/tools-and-tool-calling)和[Qwen-Agent实际适配源码](https://github.com/QwenLM/Qwen-Agent/blob/main/qwen_agent/llm/qwen_dashscope.py)：工具→结果→下一次生成与当前成熟 SDK 已能完成的机制相同。新框架仍需自行接入物间权限、领域事务及上下文；目前没有证据显示能修复本轮的资料截断、条件丢失或未接通的业务动作，因此不增加运行时依赖。

## 资料获取与图示

[Responses原生网页搜索](https://help.aliyun.com/en/model-studio/web-search)与[提取](https://help.aliyun.com/en/model-studio/web-extractor)有成熟接口，但本账户既有北京标准地址的一次兼容性实验客户端95秒未取得结果，预留费用保留；未证明具体是区域、接口权限或服务延迟。没有切换账户或声称接通。上一轮四次空来源保留。本轮不无限重试。

保留真实佳能目录→型号→实际TOC链接→正文的有限适配。补上按问题跨语言选择已发现章节；它只是检索，不认证语义。索尼支持页自动读取未成功，移除本轮未证明有效的新增路径猜测；保留失败记录，使用明确的用户/验收者提供官方URL降级，而不冒充自主搜索。

现有 pdf-parse 2.4.5（Apache-2.0）提供文本与图示限制；[Docling](https://github.com/docling-project/docling)（MIT）的布局/图表处理有潜力，但引入独立Python与模型资源不能直接补全未经读取的按键图示。本轮未安装、未声称视觉理解通过。按钮位置未知时仍需手册图示/实物核对。Tavily需要独立API授权/计费，Firecrawl有独立服务与自托管成本；本任务未授权新增收费检索服务，不为此建立账户或安装全套平台。

## 可靠行动与共享上下文

确定性数值检查改为读取当前授权的完整官方文档，与给模型的32KB片段窗口分开；同Task追问可复用其批准目标中的测量，本轮新测量优先。没有建立通用物理模拟器或商品答案表。

曾试用逐步骤资源/来源/条件的嵌套工具契约；实际序列化拖慢回复，并把“核对后排除云台”误当成“使用云台”。已简化为计划级实际资源、简短步骤、来源、未确认条件。**只在用户想保留方案时准备预览，不强制所有问答/创意输出JSON。** 服务端拦截未授权资源、已知数值失败、伪造来源；有未知条件可保存为待核对候选，不能提升为实物可行性认证。引用ID合法仍不证明操作语义正确。

复用 home_proposals 的预览、确认、过期、幂等与事务；接现有计划、私人故事、赠礼草稿、家庭事项。三个领域写入由 BEGIN 改为可嵌套 SAVEPOINT，确保与确认收据同一事务，未新增数据库或迁移私人数据。故事默认无检索/云端权限，赠礼草稿无私人故事，家人只能接收明确确认摘要。

已确认计划通过同Task重新供给当前任务，且个人Context失效后不借计划恢复旧信息；不把计划当Outcome。物品详情/可选分身对话携带原Task，专业入口返回现有页面，领域写入仍由服务端确认和授权。REA只复用固定6.8.0安装与自有软件灯，不控制实体设备。
