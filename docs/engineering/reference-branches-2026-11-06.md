# 电脑版与手机版 Git 参考分支

用户要求以两个新分支保存已经完成的完整 App，供后续参考。本轮仅整理版本快照、运行说明、公开示例截图与手机网关源代码，不改动产品流程，也不合并到原仓库现有分支。

- `reference/desktop-20261106`：电脑版入口、完整共用源码、桌面/手机参考截图。
- `reference/mobile-20261106`：手机版入口与部署边界、完整共用源码、固定入口网关参考。

两者来自同一套 Next.js 响应式 App，各自的 REFERENCE_VERSION.md 与 reference-version.json 区分交付用途，避免人为拆散共用功能。模型密钥、网关密钥、SQLite、用户上传内容、node_modules、.runtime 与构建输出均不入版本。

网关源代码从现有 Wujian-PC-Gateway 保存，仅复制 Worker、测试、构建脚本、依赖描述和无身份的配置模板；不复制 .git、Site 绑定 ID、环境密钥或打包文件。原部署账号与客户端运行安装不能仅凭 Git 分支自动恢复，需要准备自己的账号和运行配置。

最新网络结论：用户在手机关闭 VPN 时无法访问当前 chatgpt.site 入口；国内免 VPN 访问仍未解决。此状态必须与既有历史验收区分。当前链接和二维码可供技术追溯，不是国内网络可用性承诺。

本地归档与远程推送状态见最终交付记录；未取得 GitHub 写入权限前不声称已经上传。推送时仅指定上述两个新分支，不使用强制推送，不创建合并 PR，不改动已有分支、标签或仓库设置。

归档前验证：完整离线测试 239/239 通过，TypeScript 检查通过，独立 .next-reference-check 生产构建通过；网关行为测试 2/2 通过。495 个候选版本文件完成凭据及禁止入库文件扫描，未发现匹配项；没有新增真实模型费用。历史真实模型与浏览器验收仍以各阶段原报告为准。

GitHub OAuth 未授予 workflow 权限，原历史提交的 CI 文件被拒绝。为避免扩大授权，发布快照以现有远程 main 提交 21e3e11f6a13ad902b0ea32d0925b8750f172fe4 为父提交，两个参考分支均逐字沿用 main 的 .github/workflows；旧 Node CI 放在 docs/reference/original-ci 中作为普通文本参考。产品源码、素材和全部运行脚本保持归档快照不变。远程 main、develop 及其他原有分支不修改。沿用的 CI 只针对 main/develop 触发，参考分支的验证请使用本文记录的 npm 命令，不把主分支 Python CI 当成本快照的测试入口。
