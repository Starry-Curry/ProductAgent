## 现在可以体验

1. **录入陌生商品**：其他真实商品入口填品牌/型号，读取公开链接，核对后确认持有。Sony WH-CH520 经真实官网取得资料、保存到个人档案，非预置包。官方公开知识、个人报告、未知状态分开；说明书仍须型号/地区核对。
2. **独立账号的家庭协作**：各自注册/登录，确认邀请，再按物品选择共享对象。家人可以看到事项、接手和报告完成；这些状态不会冒充设备检测或短信通知。服务器忽略伪造演示身份头。
3. **选择故事赠礼**：收礼者用自己的账号预览并认领，获得独立实例。原作者与所选原话来源保留，未选故事、照片、聊天和分身不复制，新主人的私密内容不回流。
4. **分身与记忆**：原有可选形象/名字保留，独立身份下实际保存、跨会话本地召回、纠正和遗忘已经浏览器验证。没有证明新一轮真实模型的三类分身都已成熟。
5. **REA 软件闭环**：从物品资料页实际调用 REA 6.8.0 分析自有 JS 软件灯，取得接口候选，用户授权并确认后调光，再读回亮度。不是米家台灯或真实硬件。模型替身调度工具时，后台调用的 REA 和模拟器是真实进程。

## 必须保留的质量判断

- 公开资料检索原先会丢掉英文说明书中的操作/安全段；已修复。明确操作问题采用一次生成加原文校验，失败保留摘录，不自动继续付费修补。
- 自然综合的事实问答及逐字流式能力已实现，但**事实综合路径默认关闭**，仅 `WUJIAN_EXPERIMENTAL_FACT_QA=true` 显式实验启用。真实样本有“未提及→证明不支持”、编造保修政策等错误，不能默认发布。
