# 下一版迭代：我的家、物品角色与全屋 Agent

日期：2026-10-18。用户已授权在独立分支实施。本轮基线 `4394b06`，分支 `feat/home-scene-item-companions`。本文先记录设计和验收目标；完成情况以末尾实施记录及本轮验证文件为准。

## 1. 设计判断与产品不变量

每件 Owned Item 有自己的可辨识二维动画形象；点击它即可在同一个窗口询问使用方法、讲述或回顾故事、获得温和陪伴。全屋 Agent 处理找物、管理、跨物品目标与家庭安排，并将具体物品需求路由到适用 Skill。用户无需先选择“帮助/故事/陪伴”模式。

原有使用帮助、活动准备、家庭事项、发现、礼物与记忆继续保留。首页增加空间入口，并将原有较多表单收进可展开区域；五个既有业务入口不删除。列表、搜索和长辈版仍可使用，不强迫完成户型布置。

产品继续围绕物品、人与物的故事、人与人的关系。动画表现交互状态，不伪装设备感知；同款商品共用 Product Pack，不共用私人经历。家庭管理员不继承个人记忆。

## 2. 角色、全屋调度与框架选型

前台角色是同一实体物品的呈现层，不为每件物品启动一个常驻模型进程。角色按类别采用原创 SVG 外形，按物品 ID 区分配色与细节；支持待机、思考、回应和提醒状态，尊重减少动态效果设置，允许关闭动画。

全屋入口与物品入口共用现有 LangGraph + 千问 provider。新增显式路由节点：根据当前选中物品、明确物品名称、上一轮澄清状态与用户意图，选择资料帮助、故事、陪伴、找物、计划或待确认操作。存在同名/多件候选时先澄清；对未授权物品不检索、不提示其存在。选中的物品不被用户文本偷偷切换。

已核对 OpenAI 官方说明：Codex SDK/app-server 可承载程序化、持续会话和工具审批，是可研究的运行时选项。本工程已经有 LangGraph 的持久状态、检查点与千问兼容层；本轮继续复用，避免引入新的服务、凭证和进程生命周期。此选择基于当前工程依赖和任务范围，并非声称其他框架不能实现。

## 3. 界面前后对照

| 当前 | 本轮目标 |
| --- | --- |
| 首页同时显示帮助表单、案例、记忆和操作入口 | 首屏展示房间、可点击角色与统一对话；原表单可展开 |
| 先选故事、帮助或陪伴模式 | 自然表达后由路由选择技能；界面显示当前处理的物品与意图 |
| 物品只有图标/照片 | 保留照片档案，增加独立物品角色和状态动画 |
| 位置是字符串 | 增量增加房间、归一化坐标、版本与持久保存，和档案位置保持一致 |
| 多物品规划必须找入口 | 从全屋对话进入已有规划，预览后保存到原活动准备模块 |

房间先使用二维示意：客厅、厨房、书房、卧室、玄关、其他。未知位置明确落在待布置区域，不声称真实测量。支持用户调整房间和摆放；角色对话期间仍可直接问全屋问题。移动端使用上下排列，不把聊天挤进过窄侧栏。

## 4. 数据、权限与操作闭环

新增 SQLite v6 增量迁移，保留 v5→v6 备份，不重建 workspace。空间记录绑定物品身份及版本；读取按现有 canRead 过滤，修改沿用所有者权限。旧档案位置改变时使旧坐标失效，不用画面覆盖新数据。

移动物品、保存计划、创建家庭事项通过有期限的服务端行动建议完成：提出 → 展示实际影响 → 用户确认 → 事务内重查权限/身份/版本 → 幂等执行 → 返回真实结果。取消、重复确认和并发修改可恢复。模型不能直接指定任意 SQL、文件或未开放业务动作。文字回复不作为执行成功凭证。

全屋会话不意味着共享所有物品故事：每轮只读取当前目标、本人和授权范围的相关记录；目标切换不把上一件物品的私密上下文带入模型。身份、共享、遗忘和到期变化需要再次检查；演示案例继续与真实物品资源隔离。

## 5. Prompt、Loop 与记忆

统一对话 Prompt 在既有事实/过程约束上补充：当前角色和目标；用户问题与命令、事实叙述与假设/创作的区别；一次最多追问两个影响下一步的条件；承认能力边界；没有授权的历史记忆不发送云端。普通交流不强制开启人格设置，保存的昵称/风格仍为可选，不自动开启主动关怀。

Loop：路由 → 取获准 Context → 执行 Skill/只读工具 → 校验资料及动作参数 → 回答或提出行动卡 → 事务执行与回读 → 用户反馈 → 静默整理。保留现有单轮模型/工具次数和时限，离线和上游失败必须清楚显示。

人与物讲故事仍是记忆主入口。原话和派生线索分开，有来源、人物、物品、时间和范围。自动模式下明确真实叙述才能成为故事；疑问、假设、请求创作、模型生成内容不存为真实经历。默认历史记忆不上云，不调整原有逐条授权规则；新对话明确说明本次消息可能交给千问。纠正/遗忘和演示隔离沿用原屏障。

本轮不承诺完成通用语义画像、任意户型识别、语音、IoT、真实家庭账户或全品类知识。有限规则路由与精选规划如实标明；自然语言模型回复与本地回退分别显示。

## 6. 实施顺序与验收

1. 新分支、基线复验、本文档。
2. v6 空间存储、权限/并发与行动建议契约。
3. 路由接入 LangGraph，统一物品对话、全屋找物/规划/家庭安排，保留旧模式。
4. 原创 SVG 角色动画、房间视图、移动端与减少动态效果、原功能折叠入口。
5. 单元/领域反例、类型/构建/基准、隔离浏览器全旅程；更新报告与审查 ZIP。

重点验收：选择书架→讲一段真实经历→回忆→询问固定资料；全屋找物→定位角色；提出野餐目标→查看缺口→确认保存→原计划中可见；共享物品求助→预览家庭摘要→确认→原家庭事项可见；调整摆放→刷新保持；同名澄清、越权、撤权、遗忘、重复执行、过期建议和模型不可用；390px 无横向溢出，键盘可访问，减少动画有效。

本轮自动测试保持离线、独立数据库，不计作真实模型或实物验证。付费调用沿用本任务授权边界，未获新增额度不额外调用；Key 内容不读取、不打印、不入报告。交付包括实际源码、验证摘要、截图、更新报告及干净审查 ZIP。
