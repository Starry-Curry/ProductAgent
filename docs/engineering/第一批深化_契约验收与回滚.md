## 2. 模块与 API 契约

| 模块/API           | 输入与授权                                                   | 输出/错误边界                                                                              |
| ------------------ | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------ |
| workspace GET/POST | 本机模式 + 演示 actor；所有 mutation 再查对象权限            | 延续原操作；setContext 只允许本人，返回仅本人 Context                                      |
| products GET       | 本机模式；名称/型号查询                                      | 精选官方资料候选，不等于识别或确认拥有                                                     |
| ai POST            | itemId/question/mode；型号、版本、对象权限；云端偏好逐项授权 | 通过逐事实校验的结果/trace；422 型号不足，503 未配置，502 上游或校验失败，409 期间授权变化 |
| service-runs GET   | actor + 当前物品归属/型号/资源权限                           | 原运行记录列表；replay=1&runId=... 只读回放，不请求模型                                    |
| service-runs POST  | 当前授权 + succeeded 运行                                    | 用户执行反馈；重复同值幂等，冲突值拒绝                                                     |
| discover GET       | 当前 actor；scene/loadKg/perShelfKg/foodContact              | 版本绑定能力驱动候选；无依据为空，条件冲突 blocked，永不标已实测                           |
| gift GET/claim     | 不凭浏览转移；claim 再查权限与收到确认                       | 已选故事的作者显示；owner/author 分离，认领后的故事独立                                    |

模拟身份由 AUTH_MODE=local-demo 明确启用；不能以真实认证方式部署。Host/Origin/转发信息检查是本机边界，不是多用户安全身份。

## 3. 模型可靠性与回放策略

旧 validateAnswer 只检查 ID 集合；同一合法 ID 可以挂在错误电池、虚构维修或伪造实时状态上。

本批校验 exact curated fact text，answer 必须按 evidenceIds 顺序逐条拼接对应文本，uncertainties 不能作为自由断言通道。这是先关闭未经支持输出的保守方案，不将简单字符串匹配包装成语义验证。后续引入结构化原子 claim、单位/数量/否定/型号对齐与独立 entailment Evaluation，必须在正确改写、危险省略和跨型号污染基准上证明收益后再开放。

运行事件：created → identity_checked → retrieved → model_started → model_returned → validated → completed，任一错误进入 failed。每个检查点持久化；过期两分钟运行标记 interrupted，不自动重发请求。模型没有写业务状态工具。

默认只保留问题/响应散列、证据快照、通过校验的公共资料事实、阶段与指标；失败正文不落库。成功回放重做校验，失败回放只重现阶段和错误码。不能复原私人问题，也不能复现模型内部推理。回退指停止展示错误输出、保留失败证据并允许用户重新发起；没有假称“已撤销现实操作”。
