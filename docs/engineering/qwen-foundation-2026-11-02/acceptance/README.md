# 独立验收冻结包（尚未执行）

这是本轮独立验收集，不是开发 fixture，不是成功报告。独立子任务在读取产品定稿、主执行计划与启动指令后，免费核对官方资料并冻结；**Qwen/收费请求为 0，浏览器旅程均 not_run，物理设备验证为 0**。

- `questions.frozen.json`：6 个未预置准确型号，6 个品牌，每型号 3 个操作问题，共 18 题。含精确型号/地区、模拟持有身份与首答判准，不含标准答案或官方 URL 种子。
- `answers.frozen.json`：独立读页得到的关键判准、严重错误、适用来源、短引用。**开发调试期间不要读取或发送给实现模型**，验收执行时由评审读取。
- `journeys.frozen.json`：4 条浏览器纵向旅程和 10 个跨入口/权限/来源负例；不是仅测试 HTTP 或固定替身返回。
- `FREEZE_SHA256.json`：冻结文件字节哈希。题目及判准不因失败修改；修复后复跑另记，原始首答保留。
- `novelty-check.json`：在基线 Git 跟踪内容中用容忍空格/连字符的完整型号查询，排除本新目录；无源码或历史评测命中。曾考虑的另一型号因旧台账出现被淘汰，没有放入正式集。
- `source-fetch-pdf-r2.json`、`source-fetch-html.json`：免费真实获取的 HTTP/最终 URL/实际字节数和 SHA。官方全文只放在忽略的 `source-cache/`，不复制到仓库。
- `read-sources.mjs` 只免费读取已核实官方 PDF，不调用任何模型；`freeze.mjs` 是首次生成器（再运行会拒绝覆盖），其中也有答案，开发阶段勿读。`verify-freeze.mjs` 只校验完整性，不执行模型测试。

## 不可降低的判定

首答至少 **15/18** 有证据且可操作；6 个型号均不得错绑型号/地区，严重安全/权限/资源错误 **0**；4 条真实浏览器旅程 **4/4**。资料缺失如实说未知可以避免严重错误，但不能算有依据且可操作首答。正确片段、引用 ID、工具返回和界面卡片不单独代表题目或旅程通过。

模型、资料和测试输入分开检查：送模前断言准确型号在有效字段、实例状态与官方知识分层、工具确实取得目标资料；不得用人工给定官方 URL 冒充自主发现。直接 Qwen 对照提供同等有效资料，但单独记录自主检索链是否成功。题目进入调试后不得再称独立留出，保留本集第一次结果，必要的新留出另建新集而非替换本集。

## 免费来源核对的真实限制

本地第一次 Node 直连有三个 `fetch failed`；另一本成功读取后，PDF worker 转移 ArrayBuffer 导致最初仪表误记 `bytes=0`/空 SHA。该次日志保留且明确标为度量错误，**不作为字节证据**。使用当前进程 `NODE_USE_ENV_PROXY=1`（不改全局环境）及在解析前记录字节，第二次四本官方 PDF 均 200、实际 PDF 头和非零字节已确认，全文在本地可核对。Garmin 三页、ZOOM 完整 HTML 也真实 200。

免费 web 工具可读取同一官方文档，但 Garmin 手册目录入口一次工具打开失败，单章节真实获取成功；Bosch 在线章节一次重定向到 offline，正式依据改用同型号厂家 PDF，不冒充在线章节可用。KORG 的一次 web 截图缓存失败，后续使用实际 PDF 本地渲染，按钮图示已人工查看；TI、FUJIFILM、Bosch 也做了只读渲染检查。全部是**资料可取得和判准核对**，不是 App 的自主发现成功。
