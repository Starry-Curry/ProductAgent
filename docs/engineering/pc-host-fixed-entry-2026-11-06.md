## 实现

- Sites Worker ESM + 私有 R2 mailbox 提供固定 HTTPS 入口。Mac 主动通过 HTTPS 拉取浏览器请求，交给只监听 127.0.0.1:3214 的 Next.js 应用，再回传响应。无需路由器端口映射或家庭公网 IP。
- 云端主机控制接口使用随机 256 位 Bearer 密钥；密钥以 Sites secret 保存，本机文件权限 0600，不进入 Git。转发仅允许固定本机端口，拒绝绝对 URL、双斜杠和反斜杠路径；不是远程命令执行服务。
- 保留 Origin/Host、访客 HttpOnly Secure Cookie、二进制照片及响应状态。Node 24 fetch 不保留指定 Host 的实测导致跨源拒绝，已改为 node:http 本机转发；没有放宽原应用来源校验。
- Next.js 已构建程序、Node 24、依赖、公开素材和模型配置复制到 ~/Library/Application Support/Wujian Host，避免登录后台服务依赖桌面目录授权或 Codex 存活。
- macOS LaunchAgent com.wujian.pc-host：RunAtLoad + KeepAlive。开机登录当前用户后自动启动，进程异常退出由系统拉起；网络中断时退避重连。caffeinate -i 防止空闲睡眠，允许屏幕熄灭，不阻止合盖或用户主动睡眠。
- 公开演示使用独立 .runtime/public-data SQLite，不打开原开发数据库。每位访客独立；默认会话有效期 72 小时，与固定二维码期限不同。
- 本机 SQLite relay journal 记录请求 ID 和短期响应。已完成请求可复用响应；重启前未完成的写入不会盲目重复执行。过期 journal 清理，云端请求/响应定期清理；公开静态资源独立缓存。
- 公网排队上限 40、单请求体 6MB、电脑并发 4，沿用原模型并发、额度和访客限额。此版本缓冲 HTTP 响应，不提供 SSE/WebSocket 透传。

## 使用与边界

转发 artifacts/mobile-delivery/物间-手机扫码.png 或固定网址即可。电脑必须登录当前用户、联网并保持唤醒；建议接电、开盖。可以退出 Codex 和终端。START_MOBILE_SHARE.command/STOP_MOBILE_SHARE.command 分别启动和停止服务，使用说明在根目录。

电脑断电或睡眠期间 App 不可用，入口保留并展示离线页。恢复联网后自动重连，原二维码继续使用。固定地址依赖托管账号、域名、服务和网络可用，不承诺永久无条件访问。

业务数据库在本机不代表内容完全不离开本机：请求、Cookie、照片和响应会经过公网入口及短期中转；公开图片/JS 有云端缓存。公开页面不要使用私人生产信息。模型服务使用现有本机配置和原额度限制。登录时安装的是程序副本，后续源代码改动需重新安装更新。
