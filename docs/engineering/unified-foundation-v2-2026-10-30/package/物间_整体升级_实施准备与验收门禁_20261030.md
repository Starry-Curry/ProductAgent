# 物间｜整体产品升级实施准备与验收门禁

**状态：** 基于已确认的产品理念及 V1.1 实施级技术设计整理的执行检查清单，等待产品负责人决定是否批准实施；**不是已启动的 Codex 任务**。

## 0. 目标与范围

**允许一轮 Codex 做较大的整体升级**，但升级路径必须事先清楚，并通过阶段验收；不能让 Codex 自己重新解释物间、另造功能优先级、把模拟结果伪装成产品完成，或为追求组件数量扩张范围。

- 固定理念：**释放人与物的价值**；四个认知层次：**理解物 / 物与物 / 物与人 / 人与人**；四种价值释放机制：**兑现 / 创造 / 延续 / 传递**。
- 产品完整范围：真实物品录入、可靠使用问答、物与物组合、开放创造力、个性化设备探索、数字分身、故事、家庭关怀、赠礼传递、维护与生命周期；不删除现有模块来缩小测试负担。
- 工程核心：统一任务运行和 Context 契约、事实/证据服务、身份/关系/授权、能力注册、Outcome 回执、专业执行器接入、导航与跨页面连续性。
- 技术留用：优先兼容 Next.js/SQLite/LangGraph。是否改变某个局部执行器，以同质量/时间/成本可复现试验为依据。

## 1. 开始 Coding 前必须确认

1. 读完产品定稿、原 RFC V1.0、实施评审 V1.1、85 案例 JSONL 与商品资料 JSON。
2. 在实现之前给出短篇**架构冻结摘要**：哪些实体/API是核心，旧代码哪些保留/适配，哪几个关键合并与迁移风险；不得在执行中擅自改产品价值模型。
3. 明确保存旧数据与回退。任何可能删除/覆盖真实数据的迁移需要另获确认。
4. 新开独立分支和可恢复工作区，保护旧账号数据库、用户上传、密钥与既有服务。
5. 本次**不默认批准新增付费推理调用、云端部署、真实设备风险操作和对外消息发送**。离线与模拟测试可以自主进行；新付费额度须另经确认。

## 2. 阶段 Gate（允许在同一长任务内执行）

| Gate | 核心工程交付 | 最小阻断条件 |
|---|---|---|
| G0 架构冻结 | ADR、领域模型映射、TaskRun/Grant/Claim API、迁移/回退计划 | 新代码无法解释与旧状态的兼容性 |
| G1 事实内核 | 可信来源、型号版本适用、四态 Claim、否定/数字/操作规则 | QA-05、QA-06、QA-17 等仍发生无证据断言 |
| G2 任务与权限 | Task ID、Run ID、状态机、最小 Context、撤权、幂等、快照过滤 | FAMILY-07、GIFT-04、AGENT-04/07/08 越权或重复写入 |
| G3 专业能力融合 | 单物品服务、创意、分身、故事、家庭、赠礼与REA共用服务契约 | 只通过固定模拟家庭，陌生实物无法复用；工具结果冒充实物成功 |
| G4 前端与连续性 | 导航方案依据测试选择，任务跨页面继续，手机及桌面 | ENTRY-01~09 出现死路、重复录入或任务中断 |
| G5 整体验收 | 85 案逐案证据、旧回归、迁移测试、构建/浏览器、失败样本、交付文档与远端提交 | 关键事实、跨身份权限或高风险设备操作仍有阻断缺陷 |

## 3. 统一报告的最少结构

- **完成了哪些用户任务**：提供实际输入、场景、交互/执行结果和回执，不以代码量或测试数代替。
- **哪些能力真实可用**：官方文档支持、用户报告、真实 REA 软件运行、软件模拟器回读、实物验证严格分开。
- **质量与成本**：每类问答正确性和延迟（P50/P95）、长任务失败原因、模型请求/费用明细（前提是获得使用额度）、离线测试/真实浏览器结果。
- **数据与权限**：老数据可读、独立账户隔离、家庭共享撤权、赠礼后隐私、失败后安全回退。
- **未达标项**：原始错误、能否安全降级、是否影响 G5 完成；不以“以后优化”掩盖阻断缺陷。

## 4. 前端原型与受试者研究

附带的三方案原型可以做一次低成本可发现性测试。原型已通过自动化27条**预设路径的可达性冒烟测试**，不构成真实用户测试。小范围找5–8位不熟悉产品的受试者，让他们不看正确路径分别完成 ENTRY-01~09，记录第一次点击、任务是否找到、绕路与误解；三套方案采用平衡顺序以减轻学习效应。尚无用户结果前，**四入口只是优先候选，不是定案**。

## 5. 第一批必须优先跑的反例

- Sony WH-CH520：所读说明书没提 ANC，不能自动推出“不支持”；维修费用、保修政策不能编造。
- IKEA SAMLA 11L：食品接触用途不能与厂家明确限制冲突。
- DJI OM6：310g 手机超推荐重量范围；不能将相机视作兼容手机云台。
- Philips HD9252/90：不得因资料只搜到 /81 就直接套用型号级步骤。
- 家庭：邀请≠查看私人物品；共享≠共享私人故事；已读≠接手≠用户报告完成≠硬件回读；撤权后任务不能继续使用旧权限。
- 赠礼：仅转移获准故事，新主人独立物品实例和私有记忆，新记忆不回流给旧主人。
- REA：仅固定自有软件灯的真实程序分析与软件回读可称 `software_verified`；未经实物验证不得称 `hardware_verified`。
