# 当前产品、操作与验收指南（2026-10-18）

这份文档说明当前可操作的代码。产品定义仍以 V1.1 为准；任务书中的完整目标不等于当前能力。源码基线来自已导入的 2026-10-17 精简审查包，之后的开发延续当前 Git 工程，没有覆盖回旧 ZIP。

## 先打开系统

本机访问 http://127.0.0.1:3100 。未运行时，在项目根目录双击 START.cmd；依赖已安装且 Node24 已就绪。开发、构建与检测可用 scripts/windows.ps1 的 dev、build、test、typecheck、benchmark 任务。新电脑需 Node24、npm ci、npm run build、npm run start:local。

网页首页展开“第一次使用？先看这几个入口”，或访问 [/guide](http://127.0.0.1:3100/guide)。顶部角色是虚构演示身份；不同角色用于核对权限，当前没有真实登录与跨设备家庭服务。

## 本轮重点：从物品故事理解人

主要入口：**首页打开一件物品 → 故事与记录 → 与物品讲故事**。不需要先填写兴趣、人格或个人档案。

例如，对自己的相框自然讲述一段真实经历：“毕业那天妈妈送我这个相框，我喜欢手工。”叙述会进入同一物品的私人故事时间线；自动整理开启时，原始故事与明确表达的兴趣分别形成有来源的记忆。再问“聊聊以前的故事”，可从该物品的本人故事中回忆。当前这个讲述/回忆窗口使用本地处理，**不是千问自由对话或完整语义理解**。日常新增统一通过物品对话完成；记忆区仅保留现有内容的查看与纠正。首次介绍可跳过，完成后不再重复出现。

物品详情也可展开“记忆与陪伴”，查看该物品的整理结果；首页的同名入口可查看本人全部记忆、全局兴趣、来源与时间，并纠正、忘记或暂停。正常操作时无需反复确认每一条。

可选陪伴独立开启：展开“可选陪伴的交流方式”，选择普通或某件物品、称呼与语气，再保存。它是 AI 文字交流；不会拥有真实共同经历或感知实物。特定物品故事只用于对应物品的交流，不自动跨物品混入。想让模型使用某条历史私人记忆时，需逐条调整授权；默认只在本地使用。

暂停自动整理不删除已有记忆，也不停止普通会话或主动留下的原始故事保存。恢复不补采暂停期间的旧聊天与操作。忘记派生记忆会删除其正文、使旧上下文失效并阻止旧来源再提取；**原始故事作品与数据库备份另行保留**。忘记故事对话也清除从该会话整理的记忆；不是删除整个物品的故事档案。

## 新增家居案例与一次性介绍

首页可体验 8 个有官方商品资料的家居案例，包括水壶、空气炸锅、空气净化器、吸尘器、边桌、搁架、书架和推车。配套故事与偏好为合成演示内容，只用于对应案例；真实记忆列表、活动物资和模型工具不会把它们当成真实用户数据。[案例来源与操作](household-cases-and-onboarding-2026-10-18.md)列出完整来源、地域和边界。

新用户的记忆区提供一次可跳过的自然背景介绍，保存或跳过后不再出现。其他时候直接在物品故事窗口聊天；不再有反复新增画像/手写记忆的表。已有记忆仍可纠正、忘记或调整授权。

## 四条核实路径

1. **使用帮助闭环**：首页点“试试分步帮助”，确认填入 Windows 11 双击设置；再点“帮我解决”。标记第一步试过，输入“还是不行”，不会重复第一步。点“还没解决”可补充现象并继续排查。确实解决后点“解决了”，开启整理时自动保存最后一轮方法，标注本人报告。示例只填问题，不自动调用或发送。
2. **人与物的故事闭环**：打开自己的物品，讲一段真实经历；核对时间线、来源记忆、后续回忆。试用时请用合成内容，避免把示例当成自己的事实。记忆管理不强迫填写画像。
3. **兴趣与当前意愿**：在自然讲述中表达真实兴趣后，去“发现 → 结合我记下的兴趣，找点灵感”，提出“用家里的东西找点灵感”；当前精选材料允许时会参考手工兴趣。再说“今天不想手工，换个方向”，本次要求优先；不会把一天的选择永久改成“不喜欢手工”。
4. **家庭与礼物**：共享物品的使用帮助中预览求助摘要，交给家人；切换接收角色查看事项，私人对话不随之分享。礼物只选择愿意传递的原故事，接收确认与查看预览分开，新持有人的私人故事不回流。

## 技术支持与排查

- 页面“精选资料指导”表示预审来源/步骤；“AI 一般帮助/AI 选择资料”表示配置模型参与；“来自本地记录”表示本地处理或本人故事，不代表实时模型生成。错误、缺配置、等待条件均显示真实状态。
- 模型：北京百炼地址 https://dashscope.aliyuncs.com/compatible-mode/v1 ，模型 qwen-plus。已有本机配置与 Key 保持；仅服务端认证读取。新克隆复制 .env.example 为 .env.local，填 AI_API_KEY，确认费用后开启 AI_ALLOW_PAID_CALLS。不要把 .env.local 发给审查者。
- 普通问答的当前必要问题可能送给云端；历史私人记忆默认不上云。临时提问不保存会话/记忆，但问题仍可能由云端模型回答。
- 本机持久数据为 data/demo.sqlite；首次运行新版执行 v4→v5 的增量迁移并保留 .before-v4-to-v5.sqlite 备份。不要用测试覆盖日常数据库。
- 开发验证：npm test、npm run typecheck、npm run test:benchmark、npm run build、npm run test:acceptance。浏览器验收依赖 Windows Edge；acceptance 自动选择独立端口/数据库并关闭真实模型调用。
- 反馈问题请记录：版本/分支、当前角色、物品、复现步骤、页面错误。提交前去掉私人故事和凭证。项目尚未提供托管技术支持或运营 SLA。
