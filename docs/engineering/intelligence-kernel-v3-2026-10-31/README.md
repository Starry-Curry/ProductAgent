# 智能内核 V3：交付与未通过门禁的实验

本轮实现了可以接入 App 的任务拆分、动态原文检索、逐主张核对和部分回答呈现，但**没有证明 V3 比直接千问更可靠地完成生活任务，不默认启用**。原版业务路径仍是默认。`WUJIAN_EXPERIMENTAL_FACT_QA=false`、`WUJIAN_EXPERIMENTAL_KERNEL_V3=false`；本轮没有设备操作、私人库迁移或部署。

## 用户实际多得到什么

- 实验开启时，WH-CH520 的短按/长按问题不再必须落入人工预置属性表；实际模型两项都答出。开机、暂停、音量、再次配对也能保留多个子问题，而不是命中一项即结束。
- 陌生 CP1500 的装纸章能用于回答光面、张数、内外盖；陌生净化器能保留尺寸、重量、面积，同时把水洗问题单独留为未知。它们是有限真实成功，不能推广为一般商品问答成熟。
- 核对失败的具体候选和原因可在现有对话里展开，未知部分不会自动等同于整道题成功。型号、地区、来源、数值和授权有服务端必要检查。
- 纠正、遗忘、撤权以及旧任务目标中的私人内容进入新 Context 前重新检查；保留原有家庭、故事、赠礼、分身和 REA 软件实验。不是本轮重新发明长期记忆。

**仍未解决：**同一模型的语义复核会误拦正确候选，也会放过有引文却推理错误的答案；拆分经常扩大成用户没问的子问题；两次长 JSON 调用拖慢问答。跨物品创意和经验改变行动的质量没有通过真实验收。保留此实验是为了可复查、可恢复，不是默认发布。

**不能把上述成功都宣称为相对当前默认路径的新收益。**本轮三臂实测中，旧默认路径本来就能正确给出短/长按、四项耳机操作及2.4GHz，而且更快。上一轮20/71主要是另一条有限事实实验路径，不能用它替代当前默认版来制造提升。新陌生SKU的动态回答和可审计必要检查是可继续研究的增量，尚未证明默认用户任务整体变好。

## 对差异化价值的判断

物间应比裸模型多出**获准的个人物品事实、历史反馈、业务事务和实际执行结果**，而非多一次模型赞同。本轮证明这些上下文能传递、能失效、能进行确定性必要检查；尚未证明它们稳定转化为更好的行动。下一步应缩小到“一个问题所需的最小证据与行动”，优先修语义核对、子问题膨胀和失败经验的因果误用；不继续堆品牌答案或更换框架。
