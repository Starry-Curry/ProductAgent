本轮按用户要求只在 feature/demo 分支交付，不创建 PR，不更新 develop/main。

| 分支 | 内容 |
| --- | --- |
| `feat/a-memory-guidance` | 物品完整名片、创意回到阿圆、情境记忆、纠正/遗忘、资料核验、持久逐步教学和真实反馈 |

共同底座保持 SQL 事实源、ReMe 投影、一个 AgentScope 主 Agent。未引入第二套记忆或任务库，未改数据库结构。动画、模型框选、视频跟随均不写入“实物已经完成”。图解只储存在当前事项的展示元数据，过期步骤不会沿用。

## 本地查看

当前联合预览监听 `http://localhost:8015`，登录“小林的物间”。本机 `tmp/runtime/active-a-review.json` 给出两个实际任务链接和数据目录。演示用独立合成账号/拥有关系，真实公开说明书及商品图；未复制 `var/` 私人库。已有普通预览仍使用 `http://127.0.0.1:8000`。

3D 用中国大陆 LACK 白色55×55、104.499.09、**AA-2544914-1 第6页**的153551脚垫步骤。查看已生成的简图，可旋转、重看动作与看全貌；简图不是官方CAD。新版手册多了脚垫，不能套用早期视频或另一版本的安装顺序。

相机用官方 LACK 商品图制作的受控运动片段，明确不是实物录像。点击当前步骤的“用相机找这一步的位置”→“试看片段”→“定位当前帧”。多个候选或位置偏差时，可给方位提示、选候选，或“手动框选校准”。确认位置后“开始本地跟随”。片段后部遮挡时标注撤掉。也可主动开启摄像头或选自己的本地视频；只在点击定位时上传一帧，跟随在浏览器进行。

重新建立演示（不覆盖既有库）：

```powershell
.venv/Scripts/python.exe scripts/seed_a_review.py --data-dir tmp/a-review-fresh
$env:WUJIAN_DATA_DIR = (Resolve-Path tmp/a-review-fresh).Path
$env:DATABASE_URL = ''
$env:WUJIAN_SESSION_SECRET = ''
$env:WUJIAN_REA_ENABLED = 'false'
$env:WUJIAN_DEMO_MODE = 'true'
.venv/Scripts/python.exe -m wujian serve --port 8015
```

脚本仅下载公开资料。3D生成、教学提问与相机定位按钮会使用已有 `.env` 百炼配置。可加 `--video-file <本地WebM/MP4>`；官方媒体与合成视频未放进Git。清理或重建演示前关闭对应演示服务，不删除私人数据。

## 验证与剩余限制

- 联合分支离线回归 **76项通过**，OpenAPI和前端类型重新生成，生产构建通过。原生WASM与WebGL在Edge实际执行，桌面/手机布局检查。
- 真实百炼记忆测试包含按情境区分、当前要求覆盖旧偏好、纠正、遗忘后新对话。另补了重复遗忘不打断新会话的回归。未把用户明确留下的回忆墙故事当作个人记忆删掉。
- 真实 WH-CH720N 中文手册：第二台设备配对用约5秒。首答曾错用熟悉的7秒，修正后步骤与引文对应；负反馈改为先检查现象，同一事项可恢复。另补整值核对，防15秒误支持5秒，并处理常见中文数词、全角与等价时长。不能凭数字一致就证明所有操作语义正确。
- 3D实际模型生成约11.4秒，先前多余零件和相交位置失败也保留。只支持有限简单几何、连接面、移动或转动，不承诺任意复杂机构或真实装配验收。
- 相机云端约4–7秒一帧；同图另测 qwen3.6-plus约9秒并拒绝不确定目标。**自动小部件定位未通过稳定性验收**，有过认错桌腿、框在缝隙、高置信度错误和低清按钮无法定位。当前交付为半自动原型，必须让用户核对或校准，不能宣称任意实物精确定位已解决。
- 本地跟随640×400合成运动：55帧平移、20帧小角度旋转/缩放，处理中位数约18–19ms、P95约22–25ms；完全遮挡停止。相对中心误差约0.05px只来自受控图像运动，不是云端语义或真实摄像头精度。未做真实手持摄像头、复杂反光/绕转/部分遮挡的独立验收。
- 教学首轮资料搜索、读取与结构修复仍有明显延迟：成功轮约55–203秒，缓存后的接续约28–72秒。资料不足或型号不明时先观察识别，不猜按钮组合。性能与复杂泛化仍为 NOT_ACCEPTED，原始失败与复测在本机 `tmp/a-*` 分别保存，未提交日志、密钥或数据库。
