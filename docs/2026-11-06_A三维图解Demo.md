# 3D 分步图解 demo

分支 `demo/a-guidance-3d`，基于 `feat/a-memory-guidance@f8028f7`。这是可审阅原型，不是自动 CAD 或正式装配验收。

在阿圆的当前教学步骤点击“生成3D图解”。`POST /api/tasks/{task_id}/diagram` 输入 expected_version、step_id，返回同一事项板。Qwen 读取当前步骤、精确型号、实际引文和 PDF 原页图，输出 schematic/1 有限零件与连接关系。代码核验零件引用、数值范围、循环连接并求解接触位置，Bygga/Three.js 播放动画。可旋转、看全貌和重看动作；小部件连接自动展示局部。更新步骤后过期图解不再展示。

生成后不改变步骤已完成状态；保留原会话的 source_message_id。visualizations 为展示缓存，从实物方案反馈签名中排除，修改实际动作仍会使旧成功反馈失效。未增加数据库表或第二个 Agent。

复用 https://github.com/Nutlope/bygga 的 stage/drawable/materials/types/math，固定 `a02629a7d6454e2e28412ca7c11c69fa838304ff`；MIT LICENSE、NOTICE 和改动说明在 frontend/src/vendor/bygga。没有复制其商品目录或旧版生成教程。Three.js 0.186.1，类型0.186.0。

真实案例使用国内白色 LACK 55×55、货号104.499.09，对应官网链接的 AA-2544914-1 手册第6页。新版先装153551脚垫，不能照旧教程跳过。实际调用 qwen3-vl-plus：首轮23.17秒画了不属于当前页的桌面；第二轮10.61秒把脚垫中心猜在桌腿中间。失败保留在本机 tmp/a-3d-demo。第三轮引入连接面和代码接触求解，11.36秒生成一条桌腿与脚垫，表面贴合检查通过。几何尺寸仍是示意，不能拿来加工或判断公差。

69项离线测试通过，前端生产构建通过；Edge 实测 WebGL 零件与标签可见、插入动画变化、回放、全貌、1440/390布局和进度仍为pending。浏览器首轮仅看阴影变化误判过模型可见性，视觉复核发现步骤索引应从0起，已修复并重测。

重建演示数据：`python scripts/seed_3d_demo.py`，仅联网获取官方资料，不付费调用模型；按输出指定 WUJIAN_DATA_DIR 启动应用，登录“小林的物间”，打开给出的 route，再按需生成。脚本拒绝覆盖已有数据库。

依据：[国内商品页](https://www.ikea.cn/cn/zh/p/lack-la-ke-bian-zhuo-bai-se-10449909/)、[当前原始手册](https://resources.ikea.cn/cn/zh/assembly_instructions/lack-la-ke-bian-zhuo-bai-se__AA-2544914-1-2.pdf)、[Qwen3-VL](https://github.com/QwenLM/Qwen3-VL)。官方媒体留在本地数据目录，不作为代码重新发布。
