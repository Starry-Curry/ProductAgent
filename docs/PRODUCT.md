# 产品方案：物间 Wujian

## 一句话

物间是一个以真实物品为上下文的生活 Agent：它帮助用户用好已有物品、把目标变成行动、记录愿意留下的故事，并在家庭协作与记忆传递中守住权限边界。

## 问题

通用 AI 擅长回答“世界上通常怎么做”，却很少知道：

- 用户此刻真正拥有什么，型号、状态和可用条件是什么；
- 目标能否只靠手边物品完成，而不是再次推荐购买；
- 某段经历是否可以被记住、在什么任务里使用、能否交给家人；
- 模型给出的操作步骤是否有对应资料，还是只是在补全看似合理的细节；
- 家庭成员、礼物接收者和公开访客分别能看到什么。

这使得许多 AI 建议停留在“听起来不错”，却无法稳定进入真实生活。

## 目标用户

1. **物品很多的年轻家庭**：有相机、背包、厨房电器、工具和旧物，希望把已有资源变成日常体验。
2. **需要家庭协作的人**：需要把物品使用、维护或照顾任务交代给另一位成员。
3. **重视故事与隐私的用户**：愿意记录生活，但不希望私人经历成为默认训练素材或家庭成员都能读取的公共内容。
4. **面向长辈的简化使用者**：需要大字、少步骤、自然语言入口，而不是复杂菜单。

## 核心价值主张

### 1. 从“商品知识”走向“我的物品”

同一型号在不同地区版本、不同使用阶段可能对应不同资料。物间要求物品身份、资料版本和回答证据关联，避免把通用建议伪装成专属操作。

### 2. 从“灵感列表”走向“今天能做什么”

创意规划会把时间、已持有物品、排除条件、现场限制和完成标准放进同一任务，不默认推荐购买额外材料。

### 3. 从“永久记忆”走向“可授权上下文”

故事、派生记忆、会话历史和分享副本是不同对象。用户可以决定是否引用、是否上云、是否随礼物传递，也可以遗忘和纠正。

### 4. 从“一个账号看全部”走向“关系化权限”

私人故事不会因为物品共享而自动共享；礼物接收者需要预览和认领；家庭事项只引用必要的任务信息。

### 5. 从“模型自由发挥”走向“可验证行动”

服务器先校验权限和来源，再允许模型处理；最终输出还要经过结构、证据、数字、行动条件和安全语言检查。

## 产品闭环

```text
录入物品
  → 围绕物品提问或讲述
  → 获得有来源的帮助
  → 用现有物品规划下一步
  → 确认并完成家庭事项
  → 将有价值的经历整理成故事
  → 在明确授权下回忆或传递
```

每一次循环都会增加物品的真实上下文，但不会把一次聊天自动变成永久事实。

## 三个可演示差异化

| 常见方案 | 物间的做法 | 评审时能看到什么 |
| --- | --- | --- |
| 商品客服只给通用答案 | 型号、资料包、证据和限制共同进入回答 | 回答引用具体资料；缺少依据时明确拒绝专属步骤 |
| 灵感工具生成泛化清单 | 用已持有物品、时间和现场约束生成可完成动作 | 每个方案列出物品、步骤、限制和未确认事项 |
| 记忆功能默认收集一切 | 原始故事、候选记忆和分享范围分离 | 可以查看来源、暂停自动整理、遗忘候选、选择赠出内容 |

真正的壁垒不是一次 Prompt，而是“物品档案 + 可核对证据 + 任务状态 + 权限化记忆 + 可公开演示的运行边界”组合成的产品协议。

## 黑客松演示叙事

### 开场

“每个家里都有很多没有被用好的东西。通用 AI 会告诉你可以买什么，物间先问：你手上已经有什么？”

### 冲突

选择一个具体型号问操作。普通模型可能直接编按钮；物间展示它如何找资料、引用证据，并在资料不足时停下来。

### 转折

把需求从“查知识”变成“过生活”：用相机、背包和速写本完成 20 分钟创作，不购买材料，并明确结束条件。

### 情感落点

打开一条故事，说明记忆不是模型的所有物。用户可以决定它是否被回忆、是否上云、是否随礼物传给家人。

### 收束

“物间不是又一个聊天框。它把物品变成生活上下文，把建议变成行动，也把记忆决定权留给人。”

## 当前范围

已经具备：

- Next.js 可运行应用和响应式界面；
- 物品档案、资料包、说明书导入与来源跟踪；
- 本地规则、可选 Qwen 规划与 Agent 校验链路；
- 故事、记忆候选、章节整理和礼物传递；
- 家庭角色、事项与共享范围的本地演示；
- SQLite 迁移、幂等合成演示数据；
- 公开访客隔离、存储限额、模型预算和费用开关。

尚未完成或尚未充分验证：

- 生产级用户账号、真实家庭邀请和跨设备通知；
- 对任意型号的完整资料覆盖；
- 对所有食物、电器、维修或危险操作的实体验证；
- 图片/条码自动识别后的完整生产闭环；
- 控制真实 IoT 设备或感知实物状态；
- 在当前环境完成 Linux 容器和 ModelScope Volume 验收。

## 后续产品机会

1. **家庭物品健康档案**：保养周期、耗材与维修状态的主动提醒。
2. **可验证的说明书市场**：官方来源、授权翻译和地区版本管理。
3. **多模态确认录入**：拍一张照片生成候选，但必须由用户确认型号与状态。
4. **记忆可携带性**：导出、迁移和删除，而不是把用户锁在平台内。
5. **离线模型基线**：在无云环境中仍能完成资料检索、故事管理和规则规划。
6. **家庭共同记忆**：引入更细粒度的可见性、时限和撤回机制。

## 成功指标

产品指标应优先衡量真实帮助，而不是聊天次数：

- 有来源且被用户反馈“解决了问题”的物品帮助比例；
- 只使用已有物品即可完成的创意比例；
- 用户确认后保留的记忆与主动遗忘比例；
- 家庭事项被明确接手并完成的比例；
- 因证据不足而正确停止回答的比例；
- 每次有效业务结果的模型调用、Token 和等待成本；
- 公开演示中的隔离、配额和撤回测试通过率。
