## 给产品负责人的一页说明

这轮让物间更接近“先认识我的物品，再给建议”：用户说利用已登记物品时，不再把这句话当成一份无法匹配的新清单；“不要拍照”不再成为摄影目标。模型可以读取物品的 ID、品牌型号、登记材质、尺寸、状态、限制、能力和未知项，并看完工具结果再回答。不会因为换了模型就自动获得这些知识。

仍复用现有物品数据库。登记信息是用户报告，型号资料是对应来源的事实，二者都不能证明这件实物当前正常。没有填写的材质、几何结构、食品接触、耐热、承重和专属设备功能，都不会因为名称像某种产品而自动成立。

创意继续由模型根据实际物品生成，增加了物品条件与动作依赖检查。普通对话默认先给一个候选，避免一次生成三份复杂方案拖长等待；需要更多方向仍可通过原有候选参数请求。候选不合格、模型超时和用户信息不足分别记录。明确标注的本地组合是降级方案，不能当作 AI 新创意。

真实对照暴露并帮助修正了路由、错误提示和校验误拒；也仍有不合格候选。测试结论见[测试报告](TEST_REPORT.md)，不是“所有回答都智能了”。本轮没有真人盲评、真实物理实验、真实硬件控制或公开部署验证，不能证明创意惊喜度、实用性或安全性整体提升。

当前最重要的障碍是**物品事实、用户限制与候选行动之间的可核对关系**。新契约让信息可以到达模型，规则能筛掉部分明显矛盾，但不是通用物理验证器。继续叠加关键词有误拒与漏检风险；下一轮应做低风险创意的独立盲评与小范围实践验证，再决定模型、提示和校验如何改。
