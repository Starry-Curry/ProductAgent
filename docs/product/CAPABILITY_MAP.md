# 真实能力地图

2026-10-30，针对 a24bfd7 源码增量核对。历史测试不当作本轮验收。

| 模块 | 当前实际情况 | 缺口 / 依赖 | 本轮真实验收 |
|---|---|---|---|
| 1 物品身份与录入 | 手工、照片候选、编码、上传、链接可用；商品到达入口偏向三个预置包 | 陌生 SKU 的资料连续保存、型号/地区核对 | 未预置产品从资料到个人实例 |
| 2 商品知识 | 来源、摘录、官方域和型号核对、PDF 解析、版本缓存已有代码 | 非通用品牌适配；选用资料可能丢失官方索引身份 | 新型号网页/PDF，失败诚实呈现 |
| 3 问答与使用指导 | LangGraph、工具、资料回答、步骤续接可用 | 多问题覆盖和延迟质量未达标 | ≥30 真实模型问答，P50/P95 与内容逐案检查 |
| 4 统一任务与工具 | 工具权限、事务、幂等、会话、短引用已有实现 | 工具结果与真正执行状态仍需统一 | 失败/重试/恢复/撤权/readback |
| 5 用户认识与记忆 | 候选确认、纠正、遗忘、云端许可、epoch 失效已有实现 | 不能视为完整人物模型 | 跨会话、纠正/遗忘、其他身份不可读 |
| 6 故事与关系 | 片段、照片、章节、来源及赠送记忆可用 | 多人关系未用真实身份验证 | 同一物品不同人的故事边界 |
| 7 数字分身 | 可选名字、形象、风格，复用统一 Agent | 目前较多是表达层，实际帮助仍有质量问题 | 电子/日用品/纪念物三类闭环 |
| 8 家庭共享与协作 | 家庭任务、物品共享、状态代码已有；身份是本机演示 | 真实账号、邀请、已读与接手凭证 | 独立浏览器登录，逐状态交接 |
| 9 长辈关怀 | 简化界面和步骤、家庭帮助入口存在 | 无真实独立成员验收；不具备外部通知渠道 | 故障指导→家人接手→用户报告完成 |
| 10 赠礼与社交 | 明确选择故事快照、预览/认领代码存在 | 独立账号归属、撤销与认领后隐私待验 | 两身份赠礼、保留作者、新私人故事不回流 |
| 11 创造力与社区 | 自由探索、8 条有来源原理、选中后核对、反馈已接 App | 物理/资源幻觉明显；无真人盲评 | 本轮冻结，不宣称成熟，不回归为模板 |
| 12 设备能力与 REA | 仅源码预研，无真实设备控制 | 运行环境、实际 REA 分析和版本化授权适配器 | 自有 JS 虚拟灯分析→授权→执行→回读；不是硬件 |

现有 SQLite / Next.js / LangGraph 保留；没有必要预建完整知识图谱或更换运行框架。未完成项必须留在 CURRENT_STATE，不隐藏为演示成功。
