# 物间产品北极星

2026-10-30；基准 creativity-engine-v2@a24bfd7。本文件描述验收目标，不把目标写成已实现。

物间帮助用户理解、使用、重新创造已有物品，让它们承载个人经历，并在人与人之间继续产生价值。库存、模型和工具都是手段。

统一闭环：确认身份与持有 → 观察实际状态 → 结合可靠知识理解 → 给出可接续帮助 → 经授权行动 → 回读或接收用户反馈 → 保存可修正经验 → 选择性分享与传递。

正式价值机制为：**兑现、创造、延续、传递**。认知主线为：**理解物 → 物与物 → 物与人 → 人与人**。原文的“三类价值”仅为上一轮工程归纳，已由[产品共识定稿 V1.0](PRODUCT_FINAL_V1.md)取代；不能据此缩减产品范围。私人经历不能随物品默认转移；模型建议、用户报告和设备回读必须分开。

创造力 V2 暂时冻结，保留探索、原理索引、选中后条件核对及反馈。已知物理幻觉不因流程通过而消失。本轮优先基础问答、真实身份、协作、分身和授权软件设备验证。
