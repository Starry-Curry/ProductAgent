# 完整产品验收

各旅程必须同时记录真实输入、结果、身份、资料与失败。界面出现按钮不等于能力已交付。

| 旅程 | 必须跑通的闭环 | 不能混淆的结论 |
|---|---|---|
| A 新物品 | 未预置 SKU → 官方资料/说明书 → 用户核对持有 → 多问题帮助 → 实际状态修正 → 新会话 | 通用厂家事实 ≠ 私人物品实测 |
| B 再创造 | 具体物品 → 需求与自由探索 → 选中 → 条件 → 有授权工具则行动 → 反馈 | 创意 ≠ 可执行 ≠ 已验证；冻结 V2 |
| C 分身 | 自定义身份 → 获准知识/故事 → 实际使用帮助 → 纠正/遗忘 | 角色想象 ≠ 真实历史；分身不是用户 |
| D 家庭长辈 | 独立登录 → 邀请/共享 → 使用故障 → 摘要确认 → 另一成员看到/接手 → 反馈 | 创建、已读、接手、用户报告完成、设备验证分开；无外部通知不声称送达 |
| E 礼物 | 物品/选中故事/寄语 → 收礼预览 → 独立身份认领 → 独立实例与新故事 | 未选私聊/记忆/人格不转移；新主人隐私不回流 |

性能单独测普通问答、家庭任务与创意：路由、资料、工具、模型首 token、tokens、串行轮次、校验、浏览器首次有效内容及完整答复。目标：普通问答有效首响应 P50≤3 秒、完整正确 P50≤10 秒，同时报告 P95/失败/内容缺陷。
