# 演示指南

## 演示前检查

```bash
npm ci
npm run dev
```

打开 <http://127.0.0.1:3200>，确认：

- 首页可以进入演示空间；
- 物品展柜显示合成演示标记；
- 当前 `.env.local` 没有误开真实模型费用；
- 不展示用户私人照片、真实数据库、Key 或本地路径；
- 浏览器缩放适合现场屏幕，必要时切换大字模式。

无模型时仍可完成物品资料、故事、创意规则、家庭事项和礼物流程。现场网络不稳定时，不要用预置内容冒充在线生成。

## 三分钟主线

### 0:00—0:25 问题

“家里的 AI 通常知道世界上有什么，却不知道你手边有什么。物间把一件真实物品变成 Agent 的入口。”

展示首页和物品展柜。指出所有演示物品和故事都明确标为合成内容。

### 0:25—1:05 可信帮助

1. 打开“无线鼠标”。
2. 问：“这只鼠标用什么电池？接收器型号是什么？”
3. 展示回答中的资料、型号和限制。
4. 补充一句：“资料不足时，它不会为了显得聪明而补一个按钮位置。”

如果模型未开启，使用本地资料回答；明确说这是离线资料能力。

### 1:05—1:55 从物品到行动

1. 进入“发现新玩法”。
2. 选择相机、背包、速写本。
3. 输入：

   > 我只有 20 分钟，不买东西，不打印，只用手边这些东西，想做一次有三张照片作为成果的创作。

4. 展示方案中的开始条件、步骤、未确认信息和完成标准。

重点说明：系统先查找已有物品，再看时间与限制，而不是直接生成购买清单。

### 1:55—2:35 记忆归人所有

1. 进入“生活故事”。
2. 打开一条带照片的虚构演示故事，指出来源与虚构标记。
3. 返回并说明记忆策略：原故事、候选记忆和礼物副本分开，用户可以暂停、纠正和忘记。
4. 打开家庭页，说明共享物品不等于共享私人故事。

### 2:35—3:00 收束

“物间不是把更多设备接入 AI，而是让 AI 真正理解一件物品为什么重要、现在能做什么，以及哪些边界必须由人决定。”

## 八分钟扩展

### 物品与资料

- 新建一件物品，展示手动录入和可选资料导入入口。
- 说明条码/图片结果只是候选，仍需用户确认。
- 如果有稳定网络和已授权模型，再演示专属资料检索；否则使用本地资料包。

### 创意与任务

- 修改目标，例如“只能在室内、保持安静、不移动大件家具”。
- 观察方案是否保留新的限制。
- 把计划确认成准备任务，刷新后查看进度和续聊。

### 家庭协作

- 切换到另一位演示成员。
- 查看共享事项，说明本机角色不会产生真实推送到真人设备。
- 指出私人对话和未选择的故事不会随家庭事项复制。

### 礼物与记忆

- 选择一件可赠物品。
- 只勾选希望传递的故事文字，不选择照片。
- 预览接收者视角，说明认领不会获得赠送者所有私人记忆。

### 公开演示安全

如果展示 ModelScope/容器环境，额外说明：

- 访客会话和目录隔离；
- 上传、频率、存储与模型调用限额；
- 模型费用默认关闭；
- `/api/health` 只表示服务与数据库可用，不表示模型业务已成功。

## 现场失败时的讲法

| 情况 | 建议说明 |
| --- | --- |
| 模型不可用 | 这是可选能力；继续展示离线资料、规则创意和本地故事，不把回退结果说成模型生成 |
| 网络超时 | 演示真实工程边界；展示错误处理、费用闸门或重试策略 |
| 资料不足 | 这正是设计行为：系统应停止生成专属步骤并给出下一步 |
| 图片识别不准确 | 候选必须人工确认，不能直接写入正式档案 |
| 创意不够好 | 展示限制、来源和执行审计，不把模型创意称为实物已验证 |

## 禁止混淆的信息

- 25 件物品是演示数据，不是现场用户真实库存。
- 4 个预置创意不是在线模型输出。
- 4 段故事是虚构演示，不进入真实长期画像。
- 家庭事项不会自动发送给真实家人。
- 物品角色动画不表示摄像头识别或 IoT 状态感知。
- Docker 构建成功不等于 Linux 持久化 Volume 和线上 HTTPS 已完成验收。

## 评审后的问题

如果评委问“为什么不是商品客服”，回答：

> 商品客服只在购买前后围绕 SKU 服务；物间围绕用户已经拥有的东西，把资料、行动、故事、家庭关系和授权记忆连接成长期上下文。

如果评委问“模型能力不够怎么办”，回答：

> 产品价值不依赖模型一次答对所有问题。系统先保证事实和权限，再把有限模型能力放在允许的位置；不确定时停下来本身就是体验的一部分。

如果评委问“商业壁垒是什么”，回答：

> 可核对的物品档案、版本化资料、任务状态和权限化记忆会随时间形成用户上下文；单次模型输出本身不是壁垒。
