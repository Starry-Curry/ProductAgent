哪些是模型，哪些是程序与资产

部分当前实际方案
主问答、联网搜索qwen3.6-plus；主循环是 AgentScope 2.0.11。AS2 教学疑问关闭 thinking、缩小输出结构，只解释当前一步；普通问答保留原配置。不是后台给另一个 Codex 自动代答。
静态照片/手册图定位，视频云端回退qwen3-vl-plus，返回 normalized bbox、可见性和歧义判断；模型置信度不是统计校准概率。
AS2 初始步骤与确认经过审核的程序状态机与资料改写，无模型调用；自然复杂报告由同一主 Agent 判别 action，再由程序校验。不会把已展示步骤算成已完成。
AS2 3DCodex 编写的外观简图、Three.js 动画；不是 Qwen 自动重建、精确 CAD 或实机传感结果。Bygga 只作为开源渲染器使用，不限于 IKEA 物品。
本地视觉OpenCV ORB/RANSAC 与 LK 是传统视觉算法；ViTTrack 是 OpenCV Zoo 小模型，通过 ONNX Runtime Web WASM 在 CPU 执行。Three.js GPU 画图和这些 CPU 算法不能单独证明比赛要求的 GPU/NPU AI 推理。
原检索默认 ReMe BM25 + 百炼 text-embedding-v4；未启用本地模式时保持原架构。启用本地后不同时调用云嵌入。
新的本地推理Sentence-Transformers paraphrase-multilingual-MiniLM-L12-v2，384 维、多语言、Apache-2.0；OpenVINO 2026.4.1，固定 [1,128] 输入，掩码均值池化。语义候选和 ReMe 关键词用 RRF 合并，再从 SQL 重查可见性。它选出的资料直接进入回答 Agent 上下文，因此实际影响 AI 输出。

AS2 的原始 PDF 是文字转曲，文本抽取为空。原文件与渲染页保留；教学导览是按实拍及手册人工核对的改写，单独标为 reviewed_guide，不伪造 OCR 原文。大陆 HPA01 与其他地区/Smart 机型要区分；随包介绍中的营销内容和参数不能直接当成操作证据。

Intel GPU/NPU 部署与验证

用户截图显示 Core Ultra 7 356H、16GB 内存、Intel Graphics 和 Intel NPU。官方 OpenVINO 支持 Windows/Intel NPU，但具体驱动、模型编译和耗时仍必须到该机器验证。选择嵌入模型作为第一条加速路径，可以保持云问答和现有视觉辅助，不把比赛条件寄托于浏览器是否暗中启用 NPU。

uv sync --extra intel --cache-dir tmp/uv-cache
.venv\Scripts\python.exe scripts/local_ai.py download
.venv\Scripts\python.exe scripts/local_ai.py probe --device NPU --require-accelerator --seconds 30 --output tmp/npu-proof.json

$env:WUJIAN_LOCAL_EMBEDDING_DIR=(Resolve-Path var/models/multilingual-minilm).Path
$env:WUJIAN_LOCAL_AI_DEVICE='NPU'
$env:WUJIAN_LOCAL_AI_REQUIRED='true'
.venv\Scripts\python.exe -m wujian serve --port 8020

打开任务管理器“性能 → NPU”，同时运行 probe 或在应用提出真实问题。启动 required 模式会实际编译指定设备，设备缺失或失败会拒绝启动，不悄悄回退 CPU。已登录可查看 GET /api/local-ai；实际回答的 runs.events 保留 local_ai_context 回执、execution_devices、device_names、推理次数与命中的来源 ID。CPU 只用于明确选择的开发测试，不计为加速器验收。

当前开发机是 AMD + NVIDIA。已完成真实 CPU 及 GPU.0（RTX 4060）推理功能检查；这不是截图那台 Intel 电脑的 NPU 验收。模型和分词器约 480MB，下载脚本固定原作者版本并校验本地文件 SHA256；不下载执行远程 Python 代码。依赖为可选 extra，不强制所有队友安装。

当前语义排序最多取 250 个授权候选，每个输入截到 128 个 token；复杂长文的分块与大规模检索仍需进一步优化。完整 PDF 的图像页不是已经全部 OCR 成可检索文本。

复用与限制

教学控制器、图示接口、来源/权限、场景、相机调度、检索都是通用代码。新增经过校核的物品教程只需数据包和自己的图片/模型资产。未做过专门资产的物品仍可走主 Agent 资料检索、动态 plan、照片/手册页标注及 Qwen 简图；“任何物品拍完都生成准确完整教学与3D”还没有实现，不能从 AS2 的人工校核效果外推。

当前视频是外观拍摄，没有开机、布料放入、压烫动作。它可检验相机移动、视角和重定位，不能验收按键已按、温度已到或压烫成功。镜头拉远后小按键会丢失；本地小模型并不必然比清晰的参考图匹配更准。原 SUV 测试不再作为这条产品演示或验收证据，旧测试库和历史仍保留。

已解决的具体失败包括：旧回答重复当前步骤、负反馈被当成完成、清单接口可跳步、重复确认、空白视频首帧、晚到的摄像头权限错误覆盖本地视频、HEVC 解码兼容、教学习惯把整份几何放进检索上下文、快速完成 Run 不刷新状态，以及资料 CDN 的正常来源头缺失。云网络/搜索仍会失败；有失败事件就应区分检索完成与原文下载成功，不能把 HTTP 200 或模型自述当作功能验收。
