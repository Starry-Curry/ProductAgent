## 实际发现并修复的接缝

1. 新 TaskEntry.guidance 中的局部 StepEvidence JSON Schema 引用无法被父 Schema 解析，普通问答在模型调用前报 KeyError。内联局部引用后原生工具契约恢复。首次失败保留在 real-smoke.json。
2. AS2 三维及完整课程进入共同任务上下文，导致不必要膨胀。模型上下文与检索投影剔除纯展示几何和完整课程副本，仍保留当前步骤、材料和观察。
3. 普通 guidance 提示允许增量更新，但旧合并逻辑会丢失遗漏的 pending 步骤。仅对 guidance 按旧 ID／顺序合并，保留未提交的旧步骤；checklist、idea 和专用 LessonAction 语义不变。独立审查复现并在修复后重验关闭。
4. 默认共享物品照片的教学读取沿可读物品检查；额外私人照片仍做拥有者校验。纯展示图片／三维缓存不再改变业务结果签名。
5. 修复前端新依赖与类型声明、静态角色路径、WASM MIME、重复教学反馈面板、单物演示 profile 的家庭初始化前提等接入问题。
