## 证据原则

仓库会显式区分以下来源：

1. **预置演示内容**：为了让新访客看到完整体验而写入的合成数据。
2. **本地规则或资料检索**：可以离线执行，但不等于在线模型能力。
3. **模型生成内容**：来自已配置模型，仍需通过结构、证据和行动条件校验。
4. **真实验收记录**：有日期、环境、请求结果和剩余限制。
5. **产品构想**：尚未由当前代码实现的能力，只在路线图中出现。

演示图片、合成故事和 AI 生成类别图都不代表用户的真实物品、真实经历或型号实拍。
