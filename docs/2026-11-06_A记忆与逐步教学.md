# A 模块：记忆与逐步教学开发分支

基于 develop `f167344`，先带入物品名片与阿圆新玩法入口修正。仅开发分支交付，不创建 PR，不修改 develop/main。数据库结构、AgentScope 主 Agent、ReMe 检索投影与 SQL 事实源保持原架构，无迁移。

## 当前入口

物品名片的使用帮助回到阿圆。也可 `POST /api/guidance`，提交 `item_id/question/photo_ids`。明确逐步教学入口将建立 interaction/1 guidance 事项，页面展示当前步骤、观察信号、注意事项、适用引文与 PDF 页码。

`POST /api/tasks/{task_id}/guidance-feedback` 输入 `expected_version/step_id/outcome/note/photo_ids/receipt_id`，outcome 为 done、not_found、unchanged。实际报告、任务版本和主 Agent Run 同一事务提交。相同 receipt 和内容重试返回原 Run；不同内容冲突返回409。反馈不会覆写操作指令，不会将整件事标为实际完成。

同事项会话可恢复；负反馈后先核对前提和现象，再安排下一步。原生结构输出校验会将无效来源、错页、错型号、改写引句、未经用户报告的完成状态和不对应引文的操作数字返回同一 Agent 修正。可填写 source_line_start/source_line_end，由程序提取原句。最终教学文本由已校验的当前步骤生成，避免另一段自由文本追加未经核对的操作。

普通聊天、回忆、新玩法仍共用主 Agent；不是所有对话都会建立教学事项。协作者可沿原清单反馈权限更新准备进度；生成与接续教学方案仍由发起者执行，未暗中授予协作者改写他人计划的权限。

## 记忆

相同内容按 context 区分；保留临时有效期、用户报告/推测性质和来源消息。少量当前理解直接注入，较多时由已有 ReMe 检索选取，等待网络后重新从 SQL 核验。当前要求覆盖历史偏好，不需向用户复述全部记忆。

更正与遗忘使旧上下文失效，并中断其他正在使用旧理解的运行。记录回答和检索引用过的 memory_ids，遗忘后排除复述旧理解的历史对话，防止“从记忆删了、又从旧回答找回来”。旧版本没有依赖信息的对话采用退休时间保守过滤；用户仍可在界面查看原聊天，相关历史不会继续作为当前个人理解供 AI 检索。设置中可查看情境/期限，更正或遗忘。

同物品新玩法入口再次进入保留未发送文字与照片。物品名片占主要内容区，新玩法仍回阿圆；不增加导航页。

## 联网资料与本地代理

此机器代理将公开域名解析为 `198.18.0.0/15` / `2001:2::/48` Fake-IP，旧读取器会拒绝。现仅对此类**主机名**尝试 Cloudflare 公共 DoH；独立解析仍须全部为公网地址，下载固定该地址并用原 Host/TLS SNI 验证域名。字面 IP、内网地址与重定向内网目标仍拒绝。原始来源 URL 保留，不关闭证书验证。

## 实际验证与限制

- 离线全量回归66项通过；前端生产构建通过。
- Edge 1440/390 像素测试：名片、创意入口、文字照片草稿、教学信号与反馈服务不可用时保留输入；7个布局无横向溢出和页面异常。
- 真实百炼：qwen3.6-plus，独立合成账号与拥有关系；商品及来源真实。情境记忆、更正、当前要求优先、遗忘后新对话复测通过。原始首次失败和多轮复测分别保存在本机 tmp/a-live，未提交私人库或日志。
- 真实 WH-CH720N 中文指南读取：首次错误使用熟悉的7秒、资料未落库、字段位置不对、自由回复与步骤数字不一致均确实出现过，已保留并据此修复。当前原文是约5秒进入第二台设备配对，不是7秒。不同型号不得套用。
- 首轮联网教学和结构修复仍有延迟波动，已有成功轮约55–203秒，缓存资料后的接续约28–72秒；教学用同一个模型关闭长思考以减少延迟，其他模式仍沿原设置。不是毫秒级语音助手。
- 依据合法、数字一致和工程检查不证明全部语义理解正确；复杂症状、地区版本、真实物理效果仍须持续人工验收。保留 NOT_ACCEPTED 的独立验收状态，不宣称已完成所有泛化评测。

## 后续模块接入

3D 和相机 demo 分别从本分支建立独立 demo 分支，绑定同一 task_id、step_id、expected_version 和来源。动画或框选不改变实际完成状态。前端以生成的 OpenAPI 类型为准；共同修改集中在 api_models、foundation/interactions、主循环和 TaskBoard，B/C 接入时同步生成类型。

复现检查：`python -m unittest discover -s tests -v`；`python -m wujian openapi contracts/openapi.json`；`npm --prefix frontend run types`；`npm --prefix frontend run build`。普通检查不调用付费模型。
